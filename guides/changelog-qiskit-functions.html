Qiskit Functions

July 2026​

  • Qiskit Functions v0.17.0의 새로운 사전 점검 및 새로운 backend 메서드: qiskit-ibm-catalog의 새로운 메서드를 통해 실행 전에 런타임 용량과 백엔드 액세스를 확인할 수 있으며, run()은 이제 작업을 제출하기 전에 두 가지를 모두 검증합니다.

    • 새로운 기능

      • 함수에서 run()을 호출하면 서비스는 먼저 세 가지를 확인합니다: 인스턴스에 런타임 용량이 있는지, 지정한 백엔드에 접근할 수 있는지, 그리고 사용 가능한 백엔드가 하나 이상 있는지입니다. 문제가 있으면 대기열에서 기다리는 대신 즉시 명확한 오류가 표시됩니다.

        다음 리소스는 언제든지 직접 확인할 수도 있습니다:

        • usage()로 남은 런타임 용량을 확인합니다.

        • backends()로 인스턴스가 접근할 수 있는 백엔드 목록을 확인합니다.

        • backend()로 단일 백엔드를 조회하고 액세스를 확인합니다.

        • least_busy()로 대기 작업이 가장 적은 백엔드를 찾습니다.

    • 일반적인 사용 사례

      • 긴 작업 배치를 실행하기 전에 남은 용량을 확인하고, 완료하기에 충분하지 않으면 실행을 건너뜁니다.

      • 이름을 하드코딩하는 대신 코드에서 백엔드를 선택합니다.

      • 대기열에서 기다리는 대신 파이프라인과 노트북에서 빠르게 실패하도록 합니다.

    • 시작하기

      • 먼저 qiskit-ibm-catalog의 최신 버전을 사용하고 있는지 확인합니다:

        pip install --upgrade qiskit-ibm-catalog

      • 그런 다음 자세한 정보와 예제는 문서를 참조하세요.

3분기

18 July 2025​

Qiskit Functions 템플릿은 사용자 지정 실험을 위해 새로운 도구, 방법 또는 구성을 바꿔 넣을 수 있는 모듈식 파이프라인을 제공합니다. 모든 함수 템플릿은 Qiskit Serverless에도 손쉽게 배포할 수 있으며, 여기서 워크플로 실행의 일부로 클래식 컴퓨팅을 쉽게 활용할 수 있습니다. 원하는 클라우드 환경에 서버리스 패키지를 배포하거나, Premium 및 Flex Plan 사용자를 위해 IBM이 제공하는 호스팅 서비스를 활용할 수 있습니다. 어떤 옵션을 선택하든 Qiskit Serverless는 실행을 단순화하고 워크플로의 일부를 병렬화하는 데 도움이 됩니다.

자세한 내용을 알아보려면 Qiskit Functions 템플릿 가이드를 방문하거나, 문서에서 Qiskit Functions 개요를 읽어보세요.

2분기

5 June 2025​

  • 금융 및 최적화를 위한 두 개의 새로운 함수를 출시하게 되어 기쁩니다:

    • ColibriTD의 QUICK-PDE를 사용하면 재료 변형 및 전산 유체 역학 문제에 대한 특정 미분 방정식을 풀 수 있습니다. 예를 들어, 한 연구팀은 이미 QUICK-PDE 함수를 사용하여 소형 모듈형 원자로(Small Modular Reactor)로 알려진 원자로 유형에서 열을 더 효율적으로 전달하기 위해 개발된 새로운 반응성 유체의 역학을 연구하기 시작했습니다.

    • Global Data Quantum의 Quantum Portfolio Optimizer를 사용하면 정량적 금융 연구자들이 포트폴리오 최적화 전략을 백테스트할 수 있습니다. 100큐비트 이상에서 실행되는 이 함수는 지정된 기간 동안 포트폴리오의 샤프 비율 대비 수익률을 계산합니다. 초기 사용자들은 투자 전략의 과거 성과를 평가하고 유사한 조건에서 서로 다른 포트폴리오를 비교할 수 있는 옵티마이저의 기능을 탐색하고 있습니다.

16 May 2025​

  • 앞으로 몇 주 동안 모든 함수는 워크플로를 실행, 디버그 및 분석하는 데 도움이 되는 자세한 정보를 제공합니다. 여기에는 다음이 포함됩니다:

    • 작업이 실패하면 job.error_message()를 사용하여 워크플로 디버깅에 도움이 되는 구체적인 오류 코드와 메시지를 찾을 수 있습니다

    • job.status()는 Function이 RUNNING 상태일 때 발생하는 상황에 대해 더 많은 정보를 제공하며, 여기에는 다음이 포함됩니다:

      • RUNNING: MAPPING

      • RUNNING: OPTIMIZING_FOR_HARDWARE

      • RUNNING: WAITING_FOR_QPU

      • RUNNING: EXECUTING_QPU

      • RUNNING: POST_PROCESSING

    • 마지막으로, Qiskit Function이 완료된 후에는 다음 예제와 같이 job.result()['metadata']['resource_usage']로 각 단계에 소요된 시간을 확인할 수 있습니다.

코드 예제 펼쳐보기
{
      ...,
  "metadata": {
    "resource_usage": {
      {
        "RUNNING: MAPPING": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: OPTIMIZING_FOR_HARDWARE": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: WAITING_FOR_QPU": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: EXECUTING_QPU": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: POST_PROCESSING": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
      },
    }
  }
}

2024​

16 September 2024​

  • IBM Quantum Premium Plan 사용자를 위한 Qiskit Functions 프리뷰를 소개합니다. 시작하려면 pip install qiskit-ibm-catalog를 실행하고 Qiskit Functions 문서를 살펴보세요. Qiskit Functions 카탈로그 클라이언트를 사용하면 연구를 가속화하도록 설계된 추상화된 서비스에 워크로드를 제출할 수 있습니다. 기존 IBM Quantum Platform 자격 증명으로 로그인하세요.

    Qiskit Functions 카탈로그 프리뷰는 Premium Plan 사용자에게 IBM 및 다른 생태계 구성원이 작성한 함수를 포함하여 사용 가능한 함수를 탐색할 수 있는 액세스를 제공합니다. 카탈로그에는 회로 함수와 애플리케이션 함수라는 두 가지 종류의 함수가 있습니다.

    • 회로 함수는 회로 실행을 위한 단순화된 인터페이스를 제공합니다. 사용자가 제공한 추상 회로와 관측량을 입력으로 받아 대표 ISA 회로의 합성, 최적화 및 실행을 관리합니다. 회로 함수는 트랜스파일, 오류 억제 및 오류 완화의 최신 기능을 결합하여 유틸리티급 성능을 즉시 사용할 수 있도록 합니다. 이를 통해 계산 과학자는 각 문제에 대한 패턴을 처음부터 구축하는 대신 문제를 회로에 매핑하는 데 집중할 수 있습니다.

    • 애플리케이션 함수는 알고리즘 탐색이나 도메인별 사용 사례와 같은 더 높은 수준의 작업을 다룹니다. 엔터프라이즈 개발자와 데이터 과학자는 회로 작업에 필요한 양자 정보 과학 배경 지식이 없을 수 있으며, 대신 자신의 도메인 지식을 활용하여 양자 컴퓨팅 알고리즘과 애플리케이션을 발전시키고자 합니다. 애플리케이션 함수를 사용하면 사용자는 클래식 입력을 넣고 솔루션을 받아 도메인별 워크플로에 양자를 더 쉽게 접목해 볼 수 있습니다.

  • Qiskit Functions 카탈로그 출시와 함께, Premium Plan 개발자는 IBM Circuit function을 살펴볼 수 있습니다. IBM Circuit function에는 회로 합성, 최적화 및 스케줄링을 위한 최신 AI 기반 Qiskit 확장 기능과, 오늘날 하드웨어로 가능한 가장 정확한 추정치를 반환하기 위한 고급 오류 완화 방법이 포함되어 있습니다.

    사용자는 파트너인 Q-CTRL, QEDMA, Algorithmiq가 제공하는 다음 함수에 대한 라이선스를 구매할 수 있습니다.

  • 회로 함수

    • Q-CTRL은 AI 기반 양자 제어 기술을 적용하는 회로 함수를 출시하여, 사용자가 더 큰 문제로 성공적으로 확장할 수 있도록 합니다.

    • Algorithmiq는 PEC(확률적 오류 상쇄) 방법보다 적은 샷으로 추정량을 얻기 위한 오류 완화 방법인 TEM(텐서 네트워크 오류 완화)을 적용하는 회로 함수를 출시합니다.

    • QEDMA는 노이즈가 있는 QPU 작동을 효율적이고 정확하게 특성화하기 위한 독점 프로토콜을 사용하고, 특성화 데이터를 기반으로 오류 억제 및 오류 완화를 적용하는 회로 함수를 출시합니다.

  • 애플리케이션 함수

    • Q-CTRL은 사용자가 그래프나 목적 함수를 전달하여 솔루션 비용을 받을 수 있는 최적화 솔버를 출시합니다.
