텐서 네트워크를 이용한 근사 양자 컴파일 (AQC-Tensor)

텐서 네트워크를 이용한 근사 양자 컴파일(AQC-Tensor) Qiskit 애드온은 사용자가 Circuit의 초기 부분을 해당 Circuit과 거의 동등하지만 훨씬 적은 레이어를 가진 근사 형태로 컴파일할 수 있게 해줍니다. 이는 [1]에 설명된 방법을 사용하여 텐서 네트워크를 통해 수행됩니다. 주요 활용 분야는 시간 진화(time evolution)를 시뮬레이션하는 Circuit이지만, 다음 두 가지에 접근할 수 있는 모든 종류의 Circuit에 적용 가능합니다:

  1. 텐서 네트워크 시뮬레이션으로 달성할 수 있는 우수한 중간 상태, 즉 "목표 상태(target state)"를 보유하고 있으며,
  2. 목표 상태에 대한 근사를 준비하지만 목표 하드웨어 장치로 컴파일했을 때 더 적은 레이어를 가지는 좋은 Circuit이 존재합니다.

이 기법은 사용자가 최종적으로 QPU에서 실행하고자 하는 더 큰 목표 Circuit을 기반으로 ansatz Circuit을 생성합니다. 이는 먼저 텐서 네트워크 방법으로 목표 Circuit의 일부를 시뮬레이션하고, ansatz Circuit이 근사할 중간 상태의 정확한 설명을 얻음으로써 이루어집니다. 이 중간 상태가 파악되면, ansatz Circuit의 매개변수를 최적화하기 위한 비용 함수로 사용됩니다. 최적화가 완료된 후, 목표 Circuit의 나머지 부분이 ansatz에 추가되고 양자 하드웨어에서 실행됩니다.

AQC-Tensor 패키지 설치​

AQC-Tensor 패키지를 설치하는 방법은 PyPI와 소스 빌드의 두 가지가 있습니다. 패키지 의존성 간의 분리를 보장하기 위해 가상 환경에 이 패키지들을 설치하는 것을 권장합니다.

PyPI에서 설치​

AQC-Tensor 패키지를 설치하는 가장 간단한 방법은 PyPI를 통해서입니다. 패키지를 사용하려면 최소 하나의 텐서 네트워크 Backend도 설치해야 합니다. 다음 코드 스니펫은 텐서 네트워크 지원을 위한 quimb와 자동 미분을 위한 jax와 함께 애드온을 설치합니다. 관심이 있으시다면 GitHub에서 패키지를 확인해 보세요.

pip install 'qiskit-addon-aqc-tensor[quimb-jax]'

소스에서 설치​

이 패키지를 수동으로 설치하는 방법을 읽으려면 여기를 클릭하세요.

이 패키지에 기여하거나 수동으로 설치하려면 먼저 저장소를 복제하세요:

git clone git clone git@github.com:Qiskit/qiskit-addon-aqc-tensor.git

그런 다음 pip를 통해 패키지를 설치하세요. 패키지 저장소에 있는 튜토리얼을 실행할 계획이라면 노트북 의존성도 함께 설치하세요. 저장소에서 개발할 계획이라면 dev 의존성도 설치할 수 있습니다.

pip install tox jupyterlab -e '.[notebook-dependencies,dev]'

이론적 배경​

AQC-Tensor 절차는 [1]에 자세히 설명되어 있습니다. 이 섹션에서는 해당 기법의 개요를 제공합니다.

일반적으로 AQC-Tensor는 입력으로 세 가지를 필요로 합니다:

  1. 텐서 네트워크 형태의 목표 상태(target state) 설명. 이는 텐서 네트워크 시뮬레이터에서 Circuit을 시뮬레이션하여 생성하거나, 다른 방법으로 생성할 수 있습니다(예: 시간 의존 변분 원리를 사용하여 행렬 곱 상태에서 시간 진화를 수행하는 방법).
  2. 매개변수화된 ansatz Circuit. 이상적으로는 하드웨어 효율적인 연결성을 포함하여 목표 하드웨어에서 적절한 깊이를 가질 수 있는 것이어야 합니다.
  3. ansatz Circuit에 입력할 초기 매개변수. 결과 상태가 이미 목표 상태의 좋은 근사가 되도록 해야 합니다. (이는 원칙적으로 AQC에 필수적인 것은 아니지만, 최적화기에 합리적인 시작점을 제공하는 데 도움이 됩니다.)

이 기법은 ansatz Circuit이 생성하는 상태가 목표 상태에 최대한 가까워지도록 ansatz Circuit의 매개변수를 반복적으로 최적화합니다.

Ansatz 생성​

위 목록의 (2)와 (3)을 생성하기 위해, qiskit-addon-aqc 패키지는 입력 Circuit을 받아 매개변수화된 ansatz와 초기 매개변수 집합을 출력하는 generated_ansatz_from_circuit() 함수를 제공합니다. 이 함수가 반환하는 매개변수는 ansatz에 입력했을 때, 전역 위상(global phase)을 제외하고 입력 Circuit과 정확히 동등한 상태를 생성합니다.

이 함수가 생성하는 ansatz는 두-Qubit 블록당 9개의 매개변수를 사용하며, KAK 분해를 기반으로 합니다. KAK 분해는 단일-Qubit 회전을 제외하고 임의의 두-Qubit Gate를 세 개의 매개변수로 매개변수화합니다. 그런 다음 단일-Qubit 회전은 ZXZZXZZXZ로 분해되며, 각각 세 개의 매개변수를 가집니다. 이 결과로 ansatz Circuit은 원래 Circuit의 각 두-Qubit 블록에 대해 3개의 매개변수와, 두 Qubit 각각에 대한 출력 단일-Qubit 회전에 3개의 매개변수를 포함하게 됩니다(총 9개의 매개변수). 이 블록들을 추가한 후, Circuit 시작 부분의 각 활성 Qubit에 단일-Qubit 회전 레이어를 추가하여 ansatz가 완성됩니다.

텐서 네트워크 시뮬레이션​

원하는 목표 상태의 설명을 얻기 위해, 이 애드온은 행렬 곱 상태(텐서 네트워크의 가장 단순한 형태)를 사용하며 다음과 같은 텐서 네트워크 시뮬레이터를 지원합니다:

  • Qiskit Aer에 내장된 MPS 시뮬레이터
  • Quimb의 즉시(eager) CircuitMPS 시뮬레이터
  • Quimb의 지연(lazy) Circuit 시뮬레이터

텐서 네트워크에서 가장 중요한 매개변수는 최대 본드 차원(maximum bond dimension) χ\chiχ입니다. 이 매개변수는 텐서 네트워크로 표현할 수 있는 얽힘의 양을 제한하며, 따라서 주어진 Circuit을 어느 깊이까지 충실하게 시뮬레이션할 수 있는지를 결정합니다.

LLL개의 Qubit을 가진 Circuit에서, 행렬 곱 상태가 Circuit을 임의의 깊이까지 정확하게 시뮬레이션하려면 최대 χexact=2L/2\chi_{exact} = 2^{L/2}χexact​=2L/2의 본드 차원이 필요합니다. 이는 100개 이상의 Qubit에서 작동하는 일반적인 유틸리티 규모의 Circuit에서는 실현 불가능합니다. 따라서 적은 수의 Qubit으로 이 애드온을 실험하려는 경우, χ<2L/2\chi < 2^{L/2}χ<2L/2를 보장하는 것이 중요합니다. 이렇게 해야 더 큰 Circuit으로 문제를 확장할 때 목표 상태가 고전적으로 시뮬레이션 가능한 상태로 유지됩니다.
