로컬 모드에서 Qiskit Code Assistant 사용하기

로컬 머신에 Qiskit Code Assistant 모델을 설치, 구성 및 사용하는 방법을 알아봅니다.

참고 사항
  • Qiskit Code Assistant는 미리 보기 릴리스 상태이며 변경될 수 있습니다.
  • 피드백이 있거나 개발팀에 문의하고 싶다면 Qiskit Slack Workspace 채널 또는 관련 공개 GitHub 저장소를 이용해 주세요.

빠른 시작 (권장)​

로컬 모드에서 Qiskit Code Assistant를 시작하는 가장 쉬운 방법은 VS Code 또는 JupyterLab 익스텐션용 자동 설정 스크립트를 사용하는 것입니다. 이 스크립트는 LLM을 실행하기 위한 Ollama 설치, 권장 모델 다운로드, 익스텐션 구성을 자동으로 처리합니다.

VS Code 익스텐션 설정​

터미널에서 다음 명령어를 실행하세요:

bash <(curl -fsSL https://raw.githubusercontent.com/Qiskit/qiskit-code-assistant-vscode/main/setup_local.sh)

이 스크립트는 다음 단계를 수행합니다:

  • Ollama 설치 (아직 설치되지 않은 경우)
  • 권장 Qiskit Code Assistant 모델 다운로드 및 구성
  • 로컬 배포와 연동되도록 VS Code 익스텐션 설정

JupyterLab 익스텐션 설정​

터미널에서 다음 명령어를 실행하세요:

bash <(curl -fsSL https://raw.githubusercontent.com/Qiskit/qiskit-code-assistant-jupyterlab/main/setup_local.sh)

이 스크립트는 다음을 수행합니다:

  • Ollama 설치 (아직 설치되지 않은 경우)
  • 권장 Qiskit Code Assistant 모델 다운로드 및 구성
  • 로컬 배포와 연동되도록 JupyterLab 익스텐션 설정

고급 설정​

로컬 설정을 수동으로 구성하거나 설치 과정을 더 세밀하게 제어하고 싶다면 아래 섹션을 펼쳐서 확인하세요.

Hugging Face 웹사이트에서 다운로드

Hugging Face 웹사이트에서 Qiskit Code Assistant 관련 모델을 다운로드하려면 다음 단계를 따르세요:

  1. Hugging Face에서 원하는 Qiskit 모델 페이지로 이동합니다.
  2. Files and Versions 탭으로 이동하여 safetensors 또는 GGUF 모델 파일을 다운로드합니다.
Hugging Face CLI를 사용하여 다운로드

Hugging Face CLI를 사용하여 사용 가능한 Qiskit Code Assistant 모델을 다운로드하려면 다음 단계를 따르세요:

  1. Hugging Face CLI를 설치합니다.

  2. Hugging Face 계정에 로그인합니다.

    huggingface-cli login

  3. 이전 목록에서 원하는 모델을 다운로드합니다.

    huggingface-cli download <HF REPO NAME> <MODEL PATH> --local-dir <LOCAL PATH>
Ollama를 통해 로컬에 Qiskit Code Assistant 모델 수동 배포

다운로드한 Qiskit Code Assistant 모델을 배포하고 상호 작용하는 방법은 여러 가지가 있습니다. 이 가이드는 Ollama를 사용하는 방법을 설명합니다. Hugging Face Hub 통합 또는 로컬 모델을 사용하는 Ollama 애플리케이션을 이용하거나 llama-cpp-python 패키지를 사용할 수 있습니다.

Ollama 애플리케이션 사용​

Ollama 애플리케이션은 LLM을 로컬에서 실행하는 간단한 솔루션을 제공합니다. 전체 설정 과정, 모델 관리 및 상호 작용을 상당히 간단하게 만들어 주는 CLI를 갖추고 있어 사용하기 쉽습니다. 빠른 실험 및 기술적인 세부 사항을 최소화하고자 하는 사용자에게 이상적입니다.

Ollama 설치​

  1. Ollama 애플리케이션을 다운로드합니다.

  2. 다운로드한 파일을 설치합니다.

  3. 설치된 Ollama 애플리케이션을 실행합니다.

    정보
    데스크톱 메뉴 바에 Ollama 아이콘이 나타나면 애플리케이션이 성공적으로 실행 중인 것입니다. http://localhost:11434/에 접속하여 서비스가 실행 중인지 확인할 수도 있습니다.

  4. 터미널에서 Ollama를 실행해 보고 모델을 시작합니다. 예시:

    ollama run hf.co/Qiskit/Qwen2.5-Coder-14B-Qiskit

Hugging Face Hub 통합을 사용하여 Ollama 설정​

Ollama/Hugging Face Hub 통합은 새 modelfile을 생성하거나 GGUF 또는 safetensors 파일을 수동으로 다운로드하지 않고도 Hugging Face Hub에 호스팅된 모델과 상호 작용할 수 있는 방법을 제공합니다. 기본 template 및 params 파일이 Hugging Face Hub의 모델에 이미 포함되어 있습니다.

  1. Ollama 애플리케이션이 실행 중인지 확인합니다.

  2. 원하는 모델 페이지로 이동하여 URL을 복사합니다. 예: https://huggingface.co/Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF

  3. 터미널에서 다음 명령어를 실행합니다:

    ollama run hf.co/Qiskit/Qwen2.5-Coder-14B-Qiskit

hf.co/Qiskit/Qwen2.5-Coder-14B-Qiskit 모델 또는 현재 권장되는 다른 공식 GGUF 모델인 hf.co/Qiskit/mistral-small-3.2-24b-qiskit-GGUF 또는 hf.co/Qiskit/granite-3.3-8b-qiskit-GGUF를 사용할 수 있습니다.

수동으로 다운로드한 Qiskit Code Assistant GGUF 모델로 Ollama 설정​

https://huggingface.co/Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF와 같은 GGUF 모델을 수동으로 다운로드하고 다양한 템플릿 및 파라미터로 실험하려면 다음 단계를 따라 로컬 Ollama 애플리케이션에 로드할 수 있습니다.

  1. 다음 내용을 입력하여 Modelfile을 만들고, <PATH-TO-GGUF-FILE>을 다운로드한 모델의 실제 경로로 업데이트하세요.

    FROM <PATH-TO-GGUF-FILE>
    TEMPLATE """{{ if .System }}
    System:
    {{ .System }}

    {{ end }}{{ if .Prompt }}Question:
    {{ .Prompt }}

    {{ end }}Answer:
    ```python{{ .Response }}
    """

    PARAMETER stop "Question:"
    PARAMETER stop "Answer:"
    PARAMETER stop "System:"
    PARAMETER stop "```"

    PARAMETER temperature 0
    PARAMETER top_k 1

  2. Modelfile을 기반으로 커스텀 모델 인스턴스를 생성하려면 다음 명령어를 실행하세요.

    ollama create Qwen2.5-Coder-14B-Qiskit -f ./path-to-model-file
    참고
    이 과정은 Ollama가 모델 파일을 읽고, 모델 인스턴스를 초기화하고, 제공된 사양에 따라 구성하는 데 시간이 걸릴 수 있습니다.

Ollama에서 수동으로 다운로드한 Qiskit Code Assistant 모델 실행​

Qwen2.5-Coder-14B-Qiskit 모델이 Ollama에 설정된 후, 다음 명령어를 실행하여 모델을 시작하고 터미널에서 대화 모드로 상호작용하세요.

ollama run Qwen2.5-Coder-14B-Qiskit

유용한 명령어 목록:

  • ollama list - 컴퓨터의 모델 목록 표시
  • ollama rm Qwen2.5-Coder-14B-Qiskit - 모델 삭제
  • ollama show Qwen2.5-Coder-14B-Qiskit - 모델 정보 표시
  • ollama stop Qwen2.5-Coder-14B-Qiskit - 현재 실행 중인 모델 중지
  • ollama ps - 현재 로드된 모델 목록 표시
llama-cpp-python 패키지를 통해 Qiskit Code Assistant 모델을 로컬에 수동으로 배포

Ollama 애플리케이션의 대안은 llama.cpp의 Python 바인딩인 llama-cpp-python 패키지입니다. 이 패키지를 사용하면 GGUF 모델을 로컬에서 실행할 때 더 많은 제어권과 유연성을 가질 수 있으며, 로컬 모델을 워크플로우 및 Python 애플리케이션에 통합하려는 사용자에게 이상적입니다.

  1. llama-cpp-python을 설치하세요
  2. llama_cpp를 사용하여 애플리케이션 내에서 모델과 상호작용하세요. 예를 들어:
from llama_cpp import Llama

model_path = <PATH-TO-GGUF-FILE>

model = Llama(
        model_path,
        seed=17,
        n_ctx=10000,
        n_gpu_layers=37, # to offload in gpu, but put 0 if all in cpu
    )

input = 'Generate a quantum circuit with 2 qubits'
raw_pred = model(input)["choices"][0]["text"]

텍스트 생성 매개변수를 모델에 추가하여 추론을 커스터마이즈할 수도 있습니다:

generation_kwargs = {
        "max_tokens": 512,
        "echo": False, # Echo the prompt in the output
        "top_k": 1
    }

raw_pred = model(input, **generation_kwargs)["choices"][0]["text"]
Manually deploy the Qiskit Code Assistant models in local through llama.cpp

Use the llama.cpp library​

Another alternative is to use llama.cpp, an open-source library for performing LLM inference on a CPU with minimal setup. It provides low-level control over the model execution and is typically run from the command line, pointing to a local GGUF model file.

There are several ways to install llama.cpp on your machine:

  • Install llama.cpp using brew, nix, or winget
  • Run with Docker: See out the Docker documentation by llama.cpp team
  • Download pre-built binaries from the releases page
  • Build from source by cloning this repository

Once installed, you can use llama.cpp to interact with GGUF models in conversation mode as follows:

# Use a local model file
llama-cli -m my_model.gguf -cnv

# Or download and run a model directly from Hugging Face
llama-cli -hf Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF -cnv

You can also launch an OpenAI-compatible API server for the model in the following way:

llama-server -hf Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF

Advanced parameters​

With the llama-cli program, you can control the model generation using command-line options. For example, you can provide an initial “system” prompt using the -p/--prompt flag. In conversation mode (-cnv), this initial prompt acts as the system message. Otherwise, you can simply prepend any desired instruction to your prompt text. You can also adjust sampling parameters - for instance: temperature (--temp), top-k (--top-k), top-p (--top-p), repetition penalty (--repeat-penalty), and the seed to use (--seed). The following is an example invocation using these options:

llama-cli -hf Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF \
  -p "You are a friendly assistant." -cnv \
  --temp 0.7 \
  --top-k 50 \
  --top-p 0.95 \
  --repeat-penalty 1.1 \
  --seed 42

Qiskit 모델의 올바른 기능을 보장하기 위해 HF GGUF 저장소에 제공된 시스템 프롬프트를 사용하는 것을 권장합니다: mistral-small-3.2-24b-qiskit-GGUF, Qwen2.5-Coder-14B-Qiskit-GGUF, granite-3.3-8b-qiskit-GGUF, granite-3.2-8b-qiskit-GGUF의 시스템 프롬프트를 참조하세요.

로컬 배포에 익스텐션 수동 연결

Qiskit Code Assistant용 VS Code 익스텐션 및 JupyterLab 익스텐션을 사용하여 로컬에 배포된 Qiskit Code Assistant 모델에 프롬프트를 입력합니다. 모델이 설정된 Ollama 애플리케이션이 준비되면 익스텐션이 로컬 서비스에 연결되도록 구성할 수 있습니다.

Qiskit Code Assistant VS Code 익스텐션으로 연결​

Qiskit Code Assistant VS Code 익스텐션을 사용하면 코드 작성 중 모델과 상호 작용하고 코드 완성을 수행할 수 있습니다. Python 애플리케이션을 위한 Qiskit 코드 작성에 도움을 원하는 사용자에게 효과적입니다.

  1. Qiskit Code Assistant VS Code 익스텐션을 설치합니다.
  2. VS Code에서 사용자 설정으로 이동하여 Qiskit Code Assistant: Url을 로컬 Ollama 배포 URL로 설정합니다 (예: http://localhost:11434).
  3. **보기 > 명령 팔레트...**로 이동하여 개발자: 창 다시 로드를 선택하여 VS Code를 다시 로드합니다.

Ollama에 구성된 Qiskit Code Assistant 모델이 상태 표시줄에 나타나며 사용 준비가 완료됩니다.

Qiskit Code Assistant JupyterLab 익스텐션으로 연결​

Qiskit Code Assistant JupyterLab 익스텐션을 사용하면 Jupyter Notebook에서 직접 모델과 상호 작용하고 코드 완성을 수행할 수 있습니다. 주로 Jupyter Notebook으로 작업하는 사용자는 이 익스텐션을 활용하여 Qiskit 코드 작성 경험을 더욱 향상시킬 수 있습니다.

  1. Qiskit Code Assistant JupyterLab 익스텐션을 설치합니다.
  2. JupyterLab에서 설정 편집기로 이동하여 Qiskit Code Assistant Service API를 로컬 Ollama 배포 URL로 설정합니다 (예: http://localhost:11434).
