Classroom 계정 만들기

IBM Quantum® Classroom 계정은 교육자가 Open Plan에서 학생들이 IBM Quantum 하드웨어를 사용할 수 있도록 액세스를 설정하고 관리할 수 있는 간단한 방법으로, 신용카드 정보를 입력할 필요가 없습니다. Open Plan은 28일 롤링 윈도우당 10분의 quantum processing unit(QPU) 사용량을 제공합니다.

요청 제출​

이 양식을 작성하여 Classroom 계정 요청을 제출하세요.

승인된 Classroom 계정 신청자는 32자리 기능 코드가 포함된 이메일을 받게 되며, 이는 아래의 활성화 과정에서 필요합니다.

계정 ID 제출을 잊지 마세요

Classroom 계정으로 승인된 경우, 받은 확인 이메일을 삭제하지 마세요. 기능 코드 외에도 이 이메일에는 계정을 활성화할 수 있도록 새로운 계정 ID를 IBM Quantum 팀에 제출하는 방법에 대한 지침이 포함되어 있습니다. 이 마지막 단계 없이는 Classroom 계정이 활성화되지 않습니다.

계정 활성화​

승인된 Classroom 계정 신청자는 32자리 기능 코드가 포함된 이메일을 받게 됩니다. 이 이메일을 삭제하지 마세요. 계정을 설정한 후 새로운 계정 ID를 제출하는 데 필요한 중요한 정보가 포함되어 있으며, 이는 활성화를 완료하기 위한 필수 단계입니다.

기능 코드를 받은 후에는 아래의 활성화 단계를 따르세요:

신용카드 정보를 입력하지 마세요

기능 코드로 계정을 생성할 때는, 유료 계정으로 업그레이드하고 사용한 서비스에 대한 요금 청구를 받아들일 의사가 있는 경우가 아니라면 IBM Cloud®에 신용카드 정보를 제공하지 마세요.

  1. https://cloud.ibm.com/ 을 방문하세요.

  2. Create account를 클릭하세요. 개인 IBM Cloud 계정이 있더라도 새 계정을 만들어야 합니다. Classroom 계정은 개인 계정에 연결되지 않기 때문입니다.

  3. 유효한 이메일 주소와 비밀번호를 입력하세요. 기존 IBM Cloud 계정과 연결되지 않은 이메일 주소를 사용하세요. Next를 클릭하세요.

  4. 이메일 수신함에서 7자리 인증 코드를 확인한 후, 계정 생성 양식으로 돌아가세요. 새 계정을 인증하려면 해당 코드를 입력하세요.

  5. 중요: 개인 정보 섹션에서 본인의 이름과 성을 입력하지 마세요. 대신 "First name" 필드에는 소속 기관명을, "Last name" 필드에는 계정을 사용할 강의명을 입력하세요. 국가 또는 지역을 입력하세요.

  6. Account notice를 작성하고 Continue를 클릭하세요.

  7. Account privacy notice를 작성하고 Continue를 클릭하세요.

  8. Verify identity 화면에서 Register with a code를 클릭하세요.

  9. 확인 이메일에 있는 32자리 기능 코드를 Enter code 텍스트 상자에 입력한 후 Create account를 클릭하세요.

  10. IBM Quantum Platform의 계정 설정으로 이동하여 계정 ID(Details에서 확인)를 복사하세요.

  11. 받은 확인 이메일의 지침에 따라 이 ID 번호를 IBM Quantum 팀에 전송하면, 팀에서 Classroom 계정을 완전히 활성화하는 처리를 진행합니다.

사용자 추가​

  1. 먼저 IBM Quantum Platform 헤더의 계정 및 지역 전환기에서 올바른 계정과 지역이 선택되어 있는지 확인하세요.

  2. 메인 메뉴에서 Access management를 선택하세요.

  3. Users 탭에서 "Invite user"를 클릭하세요.

  4. 사용자의 이메일 주소를 입력하세요. 여러 주소를 동시에 추가할 수 있습니다.

  5. 기본적으로 각 신규 사용자에게 인스턴스가 할당됩니다. 기본 설정을 그대로 사용하는 것이 권장됩니다.

    인스턴스 이름은 사용자의 이메일 주소(@ 문자와 도메인명 제외)를 기반으로 자동 생성됩니다. "Instance naming schema" 필드에서 각 인스턴스 이름의 접두사를 사용자 지정할 수 있습니다. 예를 들어, 학생의 이메일 주소가 john-doe@university.edu이고 이 계정의 접두사로 physics-101을 지정하면, 인스턴스 이름은 physics-101-john-doe가 됩니다. 접두사를 지정하지 않으면 기본 접두사인 open-student가 사용됩니다(open-student-john-doe).

  6. 사용자는 IBM Cloud 계정을 만들고 인스턴스에 참여하라는 초대를 받게 됩니다. 계정을 만들기 위해 신용카드 정보를 입력할 필요는 없습니다.

  7. 사용자가 초대를 수락하고 계정을 생성한 후, IBM Quantum Platform으로 이동하면 페이지 헤더의 계정 전환기에서 자신의 Classroom 계정 인스턴스를 확인할 수 있습니다.

사용자 제거​

Classroom 계정에서 사용자를 제거하려면 다음 단계를 따르세요:

  1. 메인 메뉴에서 Access management를 선택하세요.

  2. Users 탭에서 해당 사용자 행 끝에 있는 세 점 메뉴를 클릭하세요.

  3. Remove user를 선택하세요. 계정에서 해당 사용자를 제거할 것인지 확인하는 메시지가 표시됩니다. 확인하려면 Remove를 클릭하세요.

인스턴스 관리​

각 인스턴스는 28일 롤링 윈도우당 최대 10분의 QPU 사용량을 제공합니다.

Classroom 계정 소유자로서, Analytics 페이지에서 계정 내 모든 인스턴스의 모든 활동을 확인할 수 있습니다.

학생 사용자는 자신의 인스턴스에서 실행된 워크로드의 데이터를 볼 수 있습니다. 다른 인스턴스의 데이터는 볼 수 없습니다.

Classroom 계정 갱신​

만료일이 임박한 Classroom 계정을 갱신하려면 이 갱신 양식을 사용하여 새로운 기능 코드를 요청하세요.
