조직을 위한 IBM Quantum Platform 구성

다음 단계에 따라 IBM Quantum Platform을 설정하세요.

1. IAM 설정 구성​

먼저, 관리자의 IAM 계정에서 다음 설정을 구성하세요. 이 설정을 검토하고 구성하려면 관리 → IAM → 설정으로 이동하세요.

  • 사용자 목록 가시성은 프로젝트 할당 여부와 관계없이 사용자가 서로를 볼 수 있는지 여부를 결정합니다. enabled 설정은 사용자 가시성을 제한합니다. 즉, 계정의 사용자는 동일한 리소스에 액세스할 수 있더라도 서로를 볼 수 없습니다. 환경에 맞는 적절한 값을 선택하세요. 자세한 내용은 사용자 가시성 제어를 참고하세요.
  • API 키 생성은 사용자가 API 키를 생성할 수 있는지 여부를 제어합니다. IBM Quantum Platform에서는 API 키를 사용하는 것이 일반적입니다. API 키를 사용하는 경우 disabled를 선택하세요. 또는 각 사용자에게 특정 권한을 부여할 수도 있습니다.

2. (선택 사항) 리소스 그룹 생성​

IBM Quantum 서비스 인스턴스를 직접 참조하는 액세스 그룹을 사용하는 경우 이 단계를 건너뛰세요.

리소스 그룹을 사용하기로 선택한 경우 관리 → 계정 → 리소스 그룹(계정 리소스 내)으로 이동하여 만들기를 클릭하세요.

3. IBM Quantum 서비스 인스턴스 생성​

이미 IBM Quantum 서비스 인스턴스를 생성한 경우 이 단계를 건너뛰세요.

  • 리소스 그룹을 사용하는 경우 적절한 리소스 그룹에 서비스 인스턴스를 생성해야 합니다.
  • QR-ml과 같은 서비스 인스턴스 이름은 액세스 그룹 참조에 필요합니다.

지침은 IBM Cloud 사용 설정의 단계를 따르세요.

4. 프로젝트를 위한 액세스 그룹 생성​

먼저, 사용자가 IBM Quantum 서비스 인스턴스를 사용하여 작업을 수행할 수 있도록 허용하는 사용자 지정 역할을 생성하세요. 그런 다음, 각 프로젝트에 대해 액세스 그룹을 생성하고 프로젝트 리소스를 사용하는 데 필요한 최소 권한 집합을 해당 그룹에 부여하세요.

5. ID 공급자 설정 및 사용자 할당​

선택한 ID 공급자에 따라 적절한 항목의 단계를 따르세요.

  • IBM Cloud 계정을 보유한 사용자의 ID 공급자로 IBM Cloud® 사용
  • IBM Cloud 계정이 없는 사용자의 ID 공급자로 IBM Cloud 사용
  • IBM Cloud 계정이 없는 사용자에 대해 IBM Cloud 이외의 ID 공급자 사용
  • 사용자 초대 및 액세스 관리

6. 방화벽 구성​

IBM Quantum API 엔드포인트에 대한 액세스를 허용하도록 방화벽을 구성하려면 다음 URL을 허용 목록에 추가하세요.

  • IBM Cloud 글로벌 서비스: 
    cloud.ibm.com
    iam.cloud.ibm.com
    api.global-search-tagging.cloud.ibm.com
    globalcatalog.cloud.ibm.com
    resource-controller.cloud.ibm.com
  • IBM Quantum Qiskit Runtime 서비스 - us-east 지역: 
    quantum.cloud.ibm.com
    s3.us-east.cloud-object-storage.appdomain.cloud
  • IBM Quantum Qiskit Runtime 서비스 - eu-de 지역: 
    eu-de.quantum.cloud.ibm.com
    s3.direct.eu-de.cloud-object-storage.appdomain.cloud
  • IBM Quantum Qiskit Functions 미리 보기 서비스: 
    qiskit-serverless.quantum.ibm.com
