횡자기장 이징 모델의 시간 전개 시뮬레이션

사용량 추정: Nighthawk r2 프로세서에서 105초 (참고: 추정치일 뿐이며 실제 실행 시간은 다를 수 있습니다.)

학습 목표​

  1. Julia를 사용해 하드웨어에서 양자 회로를 Transpile하고 실행하는 방법 배우기

  2. 측정 결과를 후처리하여 기댓값을 계산하는 방법 배우기

  3. 하드웨어 결과를 고전 시뮬레이션과 비교 평가하여 트로터 근사 오차와 하드웨어 잡음의 복합 효과를 정량화하는 방법 배우기

배경​

Julia는 주로 수치 및 과학 계산을 위해 설계된 동적 프로그래밍 언어입니다. 고성능 수치 계산 능력 덕분에 양자 시뮬레이션 워크플로에 자연스럽게 어울립니다. 이 튜토리얼에서는 Julia가 고전적인 전처리와 후처리(예: 해밀토니안 구성, ODE(상미분방정식) 풀이기 실행, 기댓값 계산)와 양자 하드웨어 잡의 조율에 모두 사용되는 방식을 보여 주며, 언어나 환경을 전환할 필요가 없습니다.

Julia에서 IBM Quantum® 하드웨어와 연동하기 위해, 이 튜토리얼은 Qiskit 생태계의 두 패키지를 사용합니다. Qiskit.jl은 Qiskit C 라이브러리를 감싸 Julia에서 회로 구성과 Transpile 기능을 제공하며, QiskitIBMRuntime.jl은 IBM Quantum Compute Service 클라이언트를 통해 IBM Quantum 하드웨어에 연결하여 Julia에서 직접 잡을 제출하고 결과를 가져올 수 있게 해 줍니다.

이 튜토리얼에서는 최근접 이웃 상호작용을 가진 1차원 사슬 위의 횡자기장 이징 모델에 대한 트로터화된 시간 전개를 다룹니다.

H=∑⟨i,j⟩JijZiZj+∑ihiXi H = \sum_{\langle i,j\rangle}J_{ij}Z_iZ_j + \sum_i h_i X_iH=⟨i,j⟩∑​Jij​Zi​Zj​+i∑​hi​Xi​

시간 전개 e−iHτe^{-iH\tau}e−iHτ를 구현하기 위해 시간 간격 τ\tauτ를 rrr개의 단계로 나누고 Δτ=τ/r\Delta\tau=\tau/rΔτ=τ/r로 정의합니다. 2차 트로터-스즈키 분해는 다음과 같습니다.

e−iHΔτ≈∏ie−ihiXiΔτ/2∏⟨i,j⟩e−iJijZiZjΔτ∏ie−ihiXiΔτ/2 e^{-iH\Delta\tau}\approx \prod_i e^{-ih_i X_i\Delta\tau/2 } \prod_{\langle i,j\rangle} e^{-iJ_{ij}Z_iZ_j\Delta\tau} \prod_i e^{-ih_iX_i\Delta\tau/2}e−iHΔτ≈i∏​e−ihi​Xi​Δτ/2⟨i,j⟩∏​e−iJij​Zi​Zj​Δτi∏​e−ihi​Xi​Δτ/2

회로 구성에서는 각 트로터 단계를 단일 큐비트 RxR_xRx​ 회전과 2큐비트 RZZR_{ZZ}RZZ​ 게이트의 연속으로 구현합니다. 회로는 번갈아 있는 큐비트에 X 게이트를 사용해 Néel 상태 ∣0101⋯ ⟩|0101\cdots\rangle∣0101⋯⟩를 준비하는 것으로 시작합니다. 이후 각 트로터 단계는 (1) 모든 큐비트에 Rx(hiΔτ)R_x(h_i\Delta\tau)Rx​(hi​Δτ), (2) 사슬을 따라 이웃한 각 쌍에 RZZ(2JijΔτ)R_{ZZ}(2J_{ij}\Delta\tau)RZZ​(2Jij​Δτ), (3) 모든 큐비트에 다시 Rx(hiΔτ)R_x(h_i\Delta\tau)Rx​(hi​Δτ)를 적용합니다. 전체 회로 깊이는 트로터 단계 수 rrr에 따라 선형으로 증가합니다.

소규모 시뮬레이터 예제​

위에서 설명한 횡자기장 Ising 모형으로 기술되는 NNN개 큐비트의 1차원 사슬을 고려합니다. 대상 시스템에 대해 아래에서 시스템 크기 N, Trotter 단계 크기 δt, 전체 Trotter 단계 수 r_max를 지정합니다. 전체 시간 발전 시간은 δt * r_max입니다. Julia는 δt와 같은 유니코드 식별자를 지원합니다. 노트북이나 Julia REPL에서 \delta를 입력한 다음 Tab을 누르면 δ가 입력됩니다. 자세한 내용은 Julia 유니코드 입력 문서를 참조하세요.

정확한 해​

양자 하드웨어에서 얻은 결과를 비교할 기준선을 마련하기 위해, 먼저 소규모 문제에 대한 고전 시뮬레이션 워크플로를 보여 드립니다. Ising 해밀토니안을 희소 행렬로 구성한 다음, OrdinaryDiffEq.jl의 ODEProblem을 사용해 슈뢰딩거 방정식을 수치적으로 적분하여 정확한 시간 발전을 구합니다. 이 접근 방식은 큐비트 수 NNN에 대해 지수적으로 증가합니다. 전체 2N2^N2N차원 상태 벡터를 저장해야 하기 때문입니다. N=20N=20N=20이면 힐베르트 공간의 차원이 이미 100만 개를 넘어 더 큰 시스템에는 적용하기 어렵습니다.

N = 20
δt = 0.05 # Trotter step size
r_max = 10 # total number of Trotter steps

h = fill(1.0, N)
J = fill(1.0, N-1)

# Build the Ising Hamiltonian as a sparse 2^n × 2^n matrix
function build_ising_hamiltonian(h::AbstractVector{<:Real}, J::AbstractVector{<:Real}, n::Int)
    dim = 2^n

    # diagonal ZZ terms
    diag_terms = zeros(Float64, dim)
    for i in 1:n-1
        for b in 0:dim-1
            bi = bit_at(b, i) # bit at position i
            bi_next = bit_at(b, i+1) # bit at position i + 1
            diag_terms[b+1] += J[i] * (1-2bi) * (1-2bi_next)
        end
    end
    H = spdiagm(0 => complex(diag_terms))

    # off-diagonal local X terms
    for i in 1:n
        mask = 1 << (i-1)
        cols = [xor(b, mask) + 1 for b in 0:dim-1]
        H += h[i] * sparse(1:dim, cols, ones(ComplexF64, dim), dim, dim)
    end
    return H
end

function z_expval_from_state(ψ::AbstractVector{<:Complex}, qubit::Int, n::Int)
    s = 0.0

다음에서는 TensorNetworkQuantumSimulator.jl이 지원하는 텐서 네트워크 방법을 사용해 노이즈 없는 회로를 고전적으로 시뮬레이션하여 회로 구성을 검증합니다. 이러한 방법은 양자 하드웨어의 결과와 비교할 기준선을 제공합니다.

먼저 named_grid((N,))를 사용해 격자를 1차원 사슬 그래프로 정의하며, 각 꼭짓점은 튜플 (i,)입니다. 그런 다음 회로 게이트를 튜플 (gate_name, qubit_indices, gate_parameter)의 리스트로 지정하며, 이는 텐서 네트워크 시뮬레이터의 입력 형식으로 사용됩니다.

# 1D chain graph — vertices are named (1,), (2,), ..., (N,)

# Gates to prepare Néel state |0101…⟩, X on every other site
neel_state_gates(n::Int) = [("X", [(i,)]) for i in 1:2:n]

# Gates for one second-order Trotter step of size δt
trotter_step_gates(h::AbstractVector{<:Real}, J::AbstractVector{<:Real}, n::Int, δt::Real) = vcat(
    [("Rx",  [(i,)],         h[i] * δt) for i in 1:n],
    [("Rzz", [(i,), (i+1,)], 2 * J[i] * δt) for i in 1:n-1],
    [("Rx",  [(i,)],         h[i] * δt) for i in 1:n])

# Make a list of gates: Néel state preparation followed by n_trotter_steps Trotter steps
function make_trotter_circuit_tn(h::AbstractVector{<:Real}, J::AbstractVector{<:Real}, n::Int, δt::Real,
                                 n_trotter_steps::Int)
    circuit = []

    # Neel state initialization
    append!(circuit, neel_state_gates(n))

    for _ in 1:n_trotter_steps
        append!(circuit, trotter_step_gates(h, J, n, δt))
    end

    return circuit
end

이제 Qiskit.jl을 사용해 Trotter화된 시간 발전 회로를 구성합니다. 이 회로는 텐서 네트워크 버전을 그대로 따릅니다. Néel 상태를 초기화하고, RxR_xRx​ 및 RZZR_{ZZ}RZZ​ 게이트로 이루어진 Trotter 단계를 rrr번 적용한 다음, 마지막으로 모든 큐비트를 Z 기저에서 측정합니다.

function make_trotter_circuit(h::AbstractVector{<:Real}, J::AbstractVector{<:Real}, n::Int, δt::Real, n_trotter_steps::Int)
    qc = QuantumCircuit(n, n)

    # Neel state initialization
    for i in 1:2:n
        x!(qc, i)
    end

    # Trotter evolution
    for _ in 1:n_trotter_steps
        for i in 1:n
            rx!(qc, h[i] * δt, i)
        end

        for i in 1:n-1
            rzz!(qc, 2* J[i] * δt, i, i+1)
        end

        for i in 1:n
            rx!(qc, h[i] * δt, i)
        end
    end

    # measure in Z basis
    for i in 1:n
        measure!(qc, i, i)
    end
    return qc
end

function two_qubit_depth(qc::QuantumCircuit)
    qubit_depth = Dict{Int,Int}()
    for inst in qc.data
        length(inst.qubits) == 2 || continue   # skip non-two-qubit gates
        d = maximum(get(qubit_depth, q, 0) for q in inst.qubits)
        for q in inst.qubits
            qubit_depth[q] = d + 1
        end
    end
    return isempty(qubit_depth) ? 0 : maximum(values(qubit_depth))
end

    s = 0.0

apply_kwargs = (; maxdim=64, cutoff=1e-10, normalize_tensors=true)

# Calculate the staggered magnetization given a tensor network state
staggered_magnetization(ψ_bpc::BeliefPropagationCache, n::Int) =
    sum((-1)^q * m for (q, m) in enumerate(z_expvals_from_tn_state(ψ_bpc, n))) / n

# Evolve a TN state and record the staggered magnetization at each step.
function compute_staggered_magnetization_tn(δt::Real, nsteps::Int; record_every::Int = 1)
    init_gates = neel_state_gates(N_large)
    step_gates = trotter_step_gates(h_large, J_large, N_large, δt)

    ψ_bpc, fid = apply_gates_to_tn_state(init_gates, tn_initial_state(g_large); apply_kwargs)
    times = [0.0]
    mags = [staggered_magnetization(ψ_bpc, N_large)]
    for k in 1:nsteps
        ψ_bpc, fid_step = apply_gates_to_tn_state(step_gates, ψ_bpc; apply_kwargs)
        fid *= fid_step
        if k % record_every == 0
            push!(times, k * δt)
            push!(mags, staggered_magnetization(ψ_bpc, N_large))
        end
    end
    println("  δt=$(round(δt, digits=5)), $(nsteps) steps: truncation fidelity ≈ $(round(fid, digits=5))")
    (times, mags)
end
