클래시컬 섀도로 잡음이 있는 양자 상태 학습하기

사용량 추정: Heron r2 프로세서에서 34분 (참고: 추정치일 뿐이며 실제 실행 시간은 다를 수 있습니다.)

학습 목표​

  • Julia에서 IBM® 양자 프로세서의 무작위 측정을 수집하고 나중에 분석할 수 있도록 저장합니다

  • 학습 전에 측정 데이터에서 결함이 있는 큐비트와 게이트를 확인합니다

  • 노이즈가 있는 상태의 행렬 곱 연산자(MPO) 모델을 classical shadow에 맞춰 피팅합니다

  • 보류한(held-out) 측정으로 모델을 검증하고 이상적인 회로와 비교합니다

사전 지식​

  • Greenberger-Horne-Zeilinger(GHZ) 상태의 Shadow tomography 튜토리얼에서 소개한 classical shadow

  • 양자 정보의 기초에서 다루는 밀도 행렬과 혼합 상태

  • 횡자기장 Ising 모델의 시간 발전 시뮬레이션 튜토리얼에서 소개한 Qiskit.jl과 QiskitIBMRuntime.jl을 사용한 Julia에서의 회로 실행

배경​

실제 양자 프로세서에서는 노이즈 때문에 회로가 준비하도록 설계된 순수 상태 ∣ψ⟩|\psi\rangle∣ψ⟩가 혼합 상태 ρ\rhoρ로 바뀝니다. 전체 양자 상태 tomography로 ρ\rhoρ를 재구성할 수 있지만, 필요한 측정 횟수는 큐비트 수에 따라 지수적으로 증가합니다. 대신 Votto 등 [1]은 무작위 측정으로부터 최대 96큐비트까지의 ρ\rhoρ에 대한 간결한 모델을 학습했습니다. 이 튜토리얼은 그들의 워크플로를 따릅니다.

무작위 측정 [2]에서는 모든 큐비트 iii를 독립적인 무작위 유니터리 uiu_iui​로 회전한 다음 계산 기저에서 측정합니다. 회전을 한 번 뽑은 것을 측정 설정(measurement setting)이라고 하며, 각 설정은 NMN_MNM​ shot 동안 반복됩니다. 결과 비트가 sis_isi​인 shot 하나는 classical shadow [3]를 줍니다.

ρ^=⨂i=1N(3 ui†∣si⟩⟨si∣ui−1),\hat\rho=\bigotimes_{i=1}^{N}\left(3\,u_i^\dagger|s_i\rangle\langle s_i|u_i-\mathbb{1}\right),ρ^​=i=1⨂N​(3ui†​∣si​⟩⟨si​∣ui​−1),

이 shadow를 설정과 shot에 대해 평균하면 ρ\rhoρ가 됩니다. 사전 지식 튜토리얼에서는 각 uiu_iui​를 세 가지 Pauli 기저에서 뽑지만, 이 튜토리얼은 논문과 마찬가지로 모든 단일 큐비트 유니터리에서 균일하게(Haar 무작위) 뽑으며, 같은 공식이 적용됩니다.

Shadow는 한 번에 소수의 큐비트에 대한 성질을 추정합니다. 논문은 이를 행렬 곱 연산자(MPO)로 결합합니다. MPO는 밀도 행렬을 큐비트당 하나씩 작은 텐서의 사슬로 나타내며, 단거리 상관관계를 갖는 노이즈 상태는 이웃한 텐서 사이에 작은 본드만 있으면 됩니다. 밀도 행렬 재규격화 군(DMRG) 알고리즘처럼 학습기는 사슬을 따라 sweep하면서 한 번에 텐서 하나를 갱신하여, 해당 텐서를 중심으로 하는 2ℓ+12\ell+12ℓ+1개 큐비트의 윈도우에서 모델이 shadow와 일치하도록 합니다(논문의 식 4). 이러한 갱신 동안 본드 차원은 고정되므로 학습기는 모델을 절단하지 않습니다. 데이터가 이 윈도우를 통해서만 들어오기 때문에, 필요한 설정 수는 사슬의 길이에 따라 증가하지 않습니다.

설정은 훈련 세트와 테스트 세트로 나뉩니다. 논문은 테스트 세트에서 ρ\rhoρ와 모델 σ\sigmaσ 사이의 최대 충실도(max fidelity)를 추정합니다.

Fmax⁡(ρ,σ)=tr(ρσ)max⁡(tr ρ2, tr σ2).\mathcal{F}_{\max}(\rho,\sigma)=\frac{\mathrm{tr}(\rho\sigma)}{\max\left(\mathrm{tr}\,\rho^2,\ \mathrm{tr}\,\sigma^2\right)}.Fmax​(ρ,σ)=max(trρ2, trσ2)tr(ρσ)​.

tr(ρσ)\mathrm{tr}(\rho\sigma)tr(ρσ)를 직접 측정하려면 지수적으로 많은 측정이 필요합니다. 대신 논문은 근사 인수분해 조건(AFC)을 가정합니다. 즉 ρ\rhoρ의 상관관계가 몇 개의 큐비트 안에서 감쇠하므로, 전역 중첩과 순도는 이웃한 kkk개 큐비트 블록에 대한 항으로 인수분해됩니다. 순도로부터 Rényi-2 엔트로피 S2=−log⁡2tr ρ2S_2=-\log_2\mathrm{tr}\,\rho^2S2​=−log2​trρ2도 얻을 수 있으며, 이는 상태가 얼마나 혼합되어 있는지를 나타냅니다.

논문은 깊이 DDD의 kicked-Ising 상태를 준비합니다.

∣ψ⟩=(∏jeiπ4ZjZj+1∏je−iπ8Xj)D∣0⟩⊗N|\psi\rangle=\left(\prod_{j} e^{i\frac{\pi}{4}Z_jZ_{j+1}}\prod_j e^{-i\frac{\pi}{8}X_j}\right)^{D}|0\rangle^{\otimes N}∣ψ⟩=(j∏​ei4π​Zj​Zj+1​j∏​e−i8π​Xj​)D∣0⟩⊗N

Eagle 프로세서인 ibm_brisbane의 96큐비트에서, D=1D=1D=1에 대해 1,024 shot씩 2,048개 설정으로 준비합니다. 논문의 그림 1(c,d)는 D=1D=1D=1에 대한 두 가지 결과를 보고합니다.

  • 학습된 모델은 N=96N=96N=96에서 실험 상태와 Fmax⁡≈75%\mathcal{F}_{\max}\approx 75\%Fmax​≈75%에 도달하며, 이는 이상적인 상태 ∣ψ⟩|\psi\rangle∣ψ⟩와 실험 상태의 중첩보다 훨씬 높습니다.

  • 엔트로피는 S2≈(0.14 내지 0.15) NS_2\approx(0.14\text{ 내지 }0.15)\,NS2​≈(0.14 내지 0.15)N으로 선형적으로 증가하며, 모델의 엔트로피는 테스트 세트에서 얻은 독립적인 추정값과 일치합니다.

이 튜토리얼은 두 결과를 모두 확인합니다. 먼저 정확한 답을 아는 8큐비트 시뮬레이션에서 확인하고, 그다음 Heron r2 프로세서인 ibm_fez에서 새로 실행한 96큐비트 실험에서 확인합니다. 학습기는 논문과 보충 자료의 방정식을 독립적으로 구현한 Julia 코드입니다.

요구 사항​

Qiskit.jl이 아직 Windows를 지원하지 않으므로(Qiskit.jl issue #15) 이 튜토리얼에는 macOS 또는 Linux가 필요합니다. 또한 다음이 필요합니다.

  • Julia 다운로드 페이지 또는 juliaup add 1.11로 설치한 Julia 1.11, 그리고 IJulia 패키지:

    julia -e 'using Pkg; Pkg.add("IJulia")'

  • 하드웨어 예제에는 96큐비트 이상의 QPU에 접근할 수 있는 IBM Quantum® Platform 계정과 저장된 자격 증명이 필요합니다. 계정이 없다면, 이 튜토리얼의 결과를 만들어 낸 ibm_fez 실행의 저장된 측정값으로 하드웨어 예제를 실행할 수 있습니다. 나머지 섹션은 계정 없이 실행됩니다.

이 노트북은 회로를 만들고 실행하기 위해 Qiskit.jl과 QiskitIBMRuntime.jl을, 무작위 측정을 위해 RandomMeas.jl [4]을(ITensors.jl과 ITensorMPS.jl도 함께 제공합니다), 그리고 NPZ.jl, JSON.jl, Plots.jl을 사용합니다. 이 튜토리얼은 Qiskit.jl 0.6.1, QiskitIBMRuntime.jl 0.3.2, RandomMeas.jl 0.3.1로 테스트되었습니다.

환경을 설정하는 방법은 두 가지입니다.

  • 옵션 1: 호환되는 최신 버전의 패키지를 임시 환경에 설치합니다. 다음 셀을 수정하지 않고 실행하세요.

  • 옵션 2: 테스트된 환경을 그대로 재현합니다. 다음 셀에서 download_toml_files = true로 설정하세요. 이 셀은 문서 저장소에서 Project.toml과 Manifest.toml을 이 노트북 옆의 env_tutorial/classical-shadows/ 폴더로 내려받은 다음, 간접 의존성을 포함하여 manifest에 기록된 모든 패키지의 정확한 버전을 설치합니다. 자세한 내용은 이 파일들에 대한 Julia 문서를 참조하세요.

using Pkg
using Downloads

download_toml_files = false

if !download_toml_files
    # Option 1: Install the latest compatible versions into a temporary environment
    Pkg.activate(mktempdir(); io=devnull)
    Pkg.add([
        PackageSpec(name="Qiskit", version="0.6"),
        PackageSpec(name="QiskitIBMRuntime", version="0.3"),
        PackageSpec(name="RandomMeas", version="0.3"),
        PackageSpec(name="NPZ"),
        PackageSpec(name="JSON"),
        PackageSpec(name="Plots"),
    ]; io=devnull)
else
    # Option 2: Install the exact tested versions recorded in Project.toml and Manifest.toml
    base_url = "https://raw.githubusercontent.com/Qiskit/documentation/main/docs/tutorials/assets/classical-shadows/julia"
    env_dir = joinpath(@__DIR__, "env_tutorial", "classical-shadows")
    mkpath(env_dir)
    for file in ("Project.toml", "Manifest.toml")
        Downloads.download("$base_url/$file", joinpath(env_dir, file))
    end
    Pkg.activate(env_dir; io=devnull)
    Pkg.instantiate(; io=devnull)
end

설정​

using RandomMeas  # also loads ITensors and ITensorMPS

using .ShadowMPOLearning
BLAS.set_num_threads(1)  # the learner multiplies many small matrices

Setup 셀이 내려받는 도우미 모듈 mpo_learning.jl이 학습기를 구현합니다. 이 튜토리얼은 여기서 다음 함수들을 호출합니다.

함수용도
kicked_ising_reference(N, D; depolarization)이상적인 kicked-Ising 상태 또는 국소 탈분극 노이즈 이후 상태의 정확한 MPO
split_settings(group; seed, train_fraction)측정 설정을 훈련 세트와 테스트 세트에 무작위로 배정(기본값은 각각 절반)
training_marginals(train; ell, prior)훈련 설정만을 사용한, 모든 학습 윈도우의 shadow 추정값
fitted_prior(ideal, train)논문에서처럼 각 윈도우의 측정된 순도에 맞춰 피팅한, 공통 무작위 측정(CRM)의 사전 분포
learn_mpo(marginals, N; ell, maxbond, sweeps)최대 혼합 상태에서 시작하여 논문의 단일 사이트 갱신을 사슬을 따라 sweep
max_fidelity(a, b), mpo_overlap(a, b)두 MPO 사이의 정확한 Fmax⁡\mathcal{F}_{\max}Fmax​와 tr(ab)\mathrm{tr}(ab)tr(ab)
afc_estimate, afc_statistics, afc_prefix_curvejackknife 오차 막대를 갖는, 테스트 설정으로부터의 Fmax⁡\mathcal{F}_{\max}Fmax​와 S2S_2S2​의 AFC 추정값

학습기는 MPO를 Pauli 기저로 저장합니다. 이렇게 하면 모델이 에르미트이고 대각합이 1로 유지되지만, 모델이 양의 반정부호가 되도록 강제하지는 않습니다. 따라서 노트북은 고유값이 얼마나 음수가 되는지 보고합니다.

소규모 시뮬레이터 예제​

모든 것을 정확하게 계산할 수 있을 만큼 작은 시스템, 즉 8큐비트의 깊이 1 kicked-Ising 상태에서 시작합니다. 하드웨어를 모사하기 위해 12%의 국소 탈분극 노이즈를 적용합니다. 노이즈가 있는 상태를 알고 있으므로 학습된 모델을 그것과 직접 비교할 수 있습니다.

1단계: 고전 입력을 양자 문제로 매핑​

kicked_ising_reference 함수는 정확한 상태를 MPO로 반환합니다. depolarization=0.12이면 회로 이후 모든 큐비트의 Bloch 벡터가 12% 줄어듭니다.

N = 8
ideal = kicked_ising_reference(N, 1)
rho = kicked_ising_reference(N, 1; depolarization=0.12)
println("Purity of the noisy state: ", round(mpo_overlap(rho, rho), digits=3))
println("F_max between the noisy and ideal states: ", round(max_fidelity(rho, ideal), digits=3))
Purity of the noisy state: 0.327
F_max between the noisy and ideal states: 0.56

2단계: 양자 하드웨어 실행에 맞게 문제 최적화​

이 예제는 측정 결과를 고전적으로 샘플링하므로 트랜스파일할 회로가 없습니다. 이 단계는 하드웨어 예제에서 다룹니다.

3단계: Qiskit primitive를 사용하여 실행​

RandomMeas.jl을 사용하여 Haar 무작위 측정 설정 2,048개를 뽑고 각각에서 256 shot을 샘플링한 다음, 설정을 훈련 세트와 테스트 세트로 균등하게 나눕니다. shot이 아니라 설정 단위로 나누세요. 같은 설정의 shot은 그 설정의 회전을 공유하므로 서로 독립적이지 않습니다.

Random.seed!(20260921)
sites = siteinds("Qubit", N)
settings = [LocalUnitaryMeasurementSetting(N; site_indices=sites, ensemble=Haar) for _ in 1:2048]
measurements = MeasurementGroup(to_itensor_mpo(rho, sites), settings, 256)
split = split_settings(measurements; seed=20260921)
println(length(split.train_ids), " training settings, ", length(split.test_ids), " testing settings")
1024 training settings,

4단계: 후처리하여 원하는 고전 형식으로 결과 반환​

1단계: 고전 입력을 양자 문제로 매핑​

각 설정에는 회로가 하나씩 필요합니다. kicked-Ising 회로, uiu_iui​를 위해 각 큐비트에 적용하는 U(θ,ϕ,λ)U(\theta,\phi,\lambda)U(θ,ϕ,λ) gate, 그리고 모든 큐비트의 측정으로 구성됩니다. vvv, ϕ/2π\phi/2\piϕ/2π, λ/2π\lambda/2\piλ/2π가 [0,1)[0,1)[0,1)에서 균일하도록 θ=2arcsin⁡v\theta=2\arcsin\sqrt{v}θ=2arcsinv​를 샘플링하면 UUU가 Haar 무작위가 됩니다. u3_matrix 함수는 4단계에서 사용하는 UUU의 행렬을 반환합니다.

u3_matrix(θ, ϕ, λ) = [cos(θ/2)              -exp(im*λ)*sin(θ/2);
                      exp(im*ϕ)*sin(θ/2)    exp(im*(ϕ + λ))*cos(θ/2)]

"Apply U(θ, ϕ, λ) to qubit q with native gates: rz(λ), sx, rz(θ + π), sx, rz(ϕ + π)."
function native_u!(qc, q, θ, ϕ, λ)
    qc.rz(λ, q)
    qc.sx(q)
    qc.rz(θ + π, q)
    qc.sx(q)
    qc.rz(ϕ + π, q)
end

"Kicked-Ising circuit on `chain`, then the rotations of one setting and a measurement."
function native_setting_circuit(chain, angles, num_device_qubits)
    n = length(chain)
    qc = QuantumCircuit(num_device_qubits, n)
    for q in chain
        native_u!(qc, q, π/4, -π/2, π/2)       # e^{-iπ/8 X}
    end
    for i in 1:n-1
        qc.cz(chain[i], chain[i + 1])          # e^{iπ/4 ZZ}, up to the S† gates below
    end
    for (i, q) in enumerate(chain)
        bonds = (i > 1) + (i < n)
        qc.rz(-π/2 * bonds, q)                 # one S† per bond
        native_u!(qc, q, angles[i, 1], angles[i, 2], angles[i, 3])
        qc.measure(q, i)                       # outcome of chain qubit i goes to bit i
    end
    qc
end

"Build a `MeasurementGroup` from the angles and a function `outcomes(r)` that returns
the (shots × N) 0/1 outcomes of setting `r`."
function measurement_group(angles, outcomes)
    settings_count, n = size(angles, 1), size(angles, 2)
    sites = siteinds("Qubit", n)
    data = map(1:settings_count) do r
        rotations = Array{ComplexF64}(undef, n, 2, 2)
        for i in 1:n
            rotations[i, :, :] = u3_matrix(angles[r, i, :]...)
        end
        MeasurementData(Int.(outcomes(r)) .+ 1;
            measurement_setting=LocalUnitaryMeasurementSetting(rotations; site_indices=sites))
    end
    MeasurementGroup(data)
end

학습하기 전에 데이터를 확인하세요. 고장 난 큐비트나 보정이 잘못된 gate가 있으면 그 주변에서 측정된 상태가 훨씬 더 혼합되며 학습기가 발산할 수도 있습니다. 이웃한 몇 개 큐비트의 순도는 이러한 노이즈에 대한 모델 비의존적 벤치마크입니다. RandomMeas.jl의 get_purity 함수는 같은 설정의 shot 쌍을 비교하여 부분계 AAA의 tr ρA2\mathrm{tr}\,\rho_A^2trρA2​를 추정합니다. 이웃한 6개 큐비트로 이루어진 모든 윈도우의 Rényi-2 엔트로피 S2=−log⁡2tr ρA2S_2=-\log_2\mathrm{tr}\,\rho_A^2S2​=−log2​trρA2​를 계산하고, 이상적인 상태의 같은 윈도우와 비교하세요. 각 윈도우는 사슬의 나머지와 얽혀 있으므로 이상적인 값은 0이 아니며, 노이즈는 이를 증가시키고, 고장 난 큐비트는 그 큐비트를 포함하는 모든 윈도우를 최댓값 6 쪽으로 밀어 올립니다.

ideal_hw = kicked_ising_reference(N_hw, 1)
width = 6

window_entropy(rho, w) = -log2(mpo_overlap(segment_mpo(rho, w), segment_mpo(rho, w)))

모든 윈도우가 이상적인 상태보다 약 0.5비트에서 1비트 정도 더 혼합되어 있으며, 노이즈가 가장 큰 구간은 사슬 위치 30~35 부근입니다. 최댓값 6에 가까운 윈도우가 없으므로 고장 난 큐비트는 없고, 분석에는 96큐비트 사슬 전체를 사용합니다. 일부 윈도우의 엔트로피가 6에 가까웠다면 그 윈도우들이 공유하는 큐비트를 제거하고, 그 큐비트 없이 사슬의 가장 긴 부분을 학습할 것입니다.

같은 순도가 CRM 사전 분포도 결정합니다. 각 윈도우에 대해 fitted_prior는 이상적인 상태를 가져와, 논문에서처럼 그 순도가 훈련 설정에서 측정된 순도와 일치하도록 국소 탈분극 세기를 피팅합니다.

다음 셀의 learn_and_validate 함수가 나머지 분석을 수행합니다. 훈련 설정으로 모델을 학습한 다음, 사슬의 처음 NNN개 큐비트에 대해 12씩 늘려 가며 테스트 설정에서 Fmax⁡\mathcal{F}_{\max}Fmax​와 S2S_2S2​를 추정합니다. 이는 논문의 그림 1(c,d)에 나오는 양입니다. 이상적인 상태는 기준선으로 같은 테스트 데이터에서 평가합니다.

이 셀은 ℓ=2\ell=2ℓ=2로 함수를 실행한 다음 ℓ=1\ell=1ℓ=1과 ℓ=0\ell=0ℓ=0으로 반복하여, 학습 윈도우의 크기가 얼마나 중요한지 확인합니다. 본드 차원은 최대 4ℓ4^\ell4ℓ이므로 ℓ=0\ell=0ℓ=0은 곱 상태, 즉 큐비트 사이의 상관관계가 없는 각 큐비트 단독의 상태를 학습합니다.

function learn_and_validate(group; ideal, ell=2, k=3, sizes=12:12:group.N, seed=20260921, train_fraction=0.5)
    split = split_settings(group; seed, train_fraction)
    prior = fitted_prior(ideal, split.train)
    marginals = training_marginals(split.train; ell, prior)
    fit = learn_mpo(marginals, group.N; ell, maxbond=min(4, 4^ell), sweeps=20)
    last(fit.history).purity <= 1 ||
        @warn "The model has purity above one, so the fit diverged. Collect more settings or shots."
    statistics = afc_statistics(split.test, k; prior)
    learned = afc_prefix_curve(fit.model, statistics, split.test.NU; k, sizes)
    baseline = afc_prefix_curve(ideal, statistics, split.test.NU; k, sizes)
    model_entropy = [-log2(mpo_overlap(prefix_mpo(fit.model, n), prefix_mpo(fit.model, n))) for n in sizes]
    (; ell, fit, split, learned, baseline, model_entropy)
end

function plot_validation(results, title)
    n = [r.n for r in first(results).learned]
    # Marker, size, and line style per ℓ. The ℓ = 1 squares are small enough to sit inside the
    # ℓ = 2 circles, so both stay visible where the two curves overlap.
    style = Dict(2 => (:circle, 7, :solid), 1 => (:rect, 3.5, :dash), 0 => (:utriangle, 5, :dot))
    fidelity = plot(yscale=:log10, ylims=(1e-6, 1.5), legend=:bottomleft, xlabel="number of qubits N",
        ylabel="held-out F_max", title=title)
    entropy = plot(xlabel="number of qubits N", ylabel="Rényi-2 entropy S₂", legend=:topleft)
    held_out = first(results).learned
    # Draw every error bar before any marker, so the bars stay behind the symbols
    for (color, result) in enumerate(results)
        scatter!(fidelity, n, [r.fidelity for r in result.learned]; yerror=[r.fidelity_sem for r in result.learned],
            markersize=0, markerstrokecolor=color, label="")
    end
    scatter!(entropy, n, [r.entropy for r in held_out]; yerror=[r.entropy_sem for r in held_out],
        markersize=0, markerstrokecolor=:black, label="")
    for (color, result) in enumerate(results)
        marker, markersize, linestyle = style[result.ell]
        label = "learned model, ℓ = $(result.ell)"
        plot!(fidelity, n, [r.fidelity for r in result.learned]; color, marker, markersize, linestyle,
            markerstrokewidth=0, label)
        plot!(entropy, n, result.model_entropy; color, linestyle, linewidth=2, label)
    end
    plot!(fidelity, n, [r.fidelity for r in first(results).baseline]; marker=:diamond, markersize=5,
        linestyle=:dashdot, color=:black, label="ideal state")
    scatter!(entropy, n, [r.entropy for r in held_out]; marker=:circle, markersize=4, color=:black,
        label="held-out AFC estimate")
    plot(fidelity, entropy; layout=(1, 2), size=(1000, 400), left_margin=7Plots.mm, bottom_margin=7Plots.mm)
end

function summarize(result)
    final = last(result.learned)
    println("ℓ = ", result.ell, ", N = ", final.n, ": held-out F_max = ", round(final.fidelity, sigdigits=3), " ± ",
        round(final.fidelity_sem, sigdigits=2), " (ideal state: ", round(last(result.baseline).fidelity, sigdigits=2), ")")
    println("  S₂ = ", round(final.entropy, digits=2), " ± ", round(final.entropy_sem, digits=2),
        " held out; ", round(last(result.model_entropy), digits=2), " from the model")
    lowest = minimum(minimum(eigvals(Hermitian(operator_from_coefficients(local_coefficients(result.fit.model, w)))))
                     for w in unique(learning_windows(final.n, max(result.ell, 1))))
    println("  Most negative eigenvalue in any learning window: ", round(lowest, digits=4))
end

results_hw = [learn_and_validate(group_hw; ideal=ideal_hw, ell) for ell in (2, 1, 0)]
foreach(summarize, results_hw)
plot_validation(results_hw, "ibm_fez, 96-qubit chain")

이 결과는 다른 프로세서에서 논문의 두 주장을 모두 재현합니다.

  • 모델은 이상적인 상태보다 데이터를 훨씬 더 잘 설명합니다. N=96N=96N=96에서 ℓ=2\ell=2ℓ=2 모델의 보류 Fmax⁡\mathcal{F}_{\max}Fmax​는 0.59 ± 0.10이며, 이상적인 상태는 0.0035입니다. 논문은 ibm_brisbane에서 약 0.75를 보고합니다.

  • 모델의 엔트로피는 모든 NNN에서 테스트 데이터와 일치합니다. N=96N=96N=96에서 모델은 10.2, 테스트 데이터는 10.0 ± 0.3이며, 즉 S2/N≈0.10S_2/N\approx 0.10S2​/N≈0.10으로, 이전 세대인 ibm_brisbane의 0.14~0.15와 비교됩니다.

윈도우 크기를 비교하면 정보가 어디에 있는지 알 수 있습니다. ℓ=1\ell=1ℓ=1이면 모델이 거의 그만큼 좋으므로(Fmax⁡=0.55±0.09\mathcal{F}_{\max}=0.55\pm0.09Fmax​=0.55±0.09), 이 데이터에서는 몇 개 큐비트를 넘어서는 상관관계가 거의 도움이 되지 않습니다. ℓ=0\ell=0ℓ=0이면 곱 상태가 이웃한 큐비트 사이의 얽힘을 놓칩니다. 엔트로피는 10 대신 32까지 증가하고, Fmax⁡\mathcal{F}_{\max}Fmax​는 이상적인 상태보다도 더 빠르게 떨어져 N=96N=96N=96에서 6×10−66\times10^{-6}6×10−6이 됩니다.

이 수치를 읽을 때는 다음 한계를 염두에 두세요.

  • 훈련 분할. 오차 막대는 테스트 데이터의 통계 오차만 포함합니다. 같은 설정을 다른 방식으로 무작위 분할하면 ℓ=2\ell=2ℓ=2, N=96N=96N=96에서 Fmax⁡\mathcal{F}_{\max}Fmax​가 0.49에서 0.59 사이로 나옵니다.

  • 마지막 sweep. 학습기는 항상 마지막 sweep의 모델을 반환하므로 테스트 데이터가 모델에 영향을 주지 않습니다.

  • 양의 반정부호성. 모델은 양의 반정부호로 제한되지 않으며, 학습 윈도우에서 가장 작은 고유값은 약 −0.05-0.05−0.05입니다. 따라서 모델의 Fmax⁡\mathcal{F}_{\max}Fmax​와 S2S_2S2​는 물리적 상태에 대해 보증된 성질이 아니라 하나의 연산자를 설명합니다.

  • 인수분해. 보류한 모든 추정값은 AFC 가정에 의존하며, 이 가정은 측정 자체로는 보증할 수 없습니다.

  • 깊이 2에 대한 논문의 매개변수(ℓ=3\ell=3ℓ=3, 최대 본드 차원 8)로 깊이 2에서 실험을 반복하고, 학습기에 필요한 측정 설정의 수를 확인해 보세요.
