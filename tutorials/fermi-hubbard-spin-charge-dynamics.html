Fermi-Hubbard 모델의 스핀 및 전하 동역학

사용량 추정: Heron r3 프로세서에서 5분. (참고: 추정치일 뿐이며 실제 실행 시간은 다를 수 있습니다.)

배경​

Fermi-Hubbard 모델은 전자가 격자 위에서 도약(hopping)하며 이중 점유에 에너지 페널티가 부과되는 상황을 기술합니다. 경계가 열린 LLL개 사이트의 1차원 사슬에서 해밀토니안은 다음과 같이 정의됩니다.

H=−∑i=0L−2∑σ∈{↑,↓}th,i(ciσ†ci+1,σ+h.c.)+∑i=0L−1Ui ni↑ni↓−∑i=0L−1∑σμi niσ,H = -\sum_{i=0}^{L-2} \sum_{\sigma \in \{\uparrow,\downarrow\}} t_{h,i} \left( c^\dagger_{i\sigma} c_{i+1,\sigma} + \mathrm{h.c.} \right) + \sum_{i=0}^{L-1} U_i\, n_{i\uparrow} n_{i\downarrow} - \sum_{i=0}^{L-1} \sum_\sigma \mu_i\, n_{i\sigma},H=−i=0∑L−2​σ∈{↑,↓}∑​th,i​(ciσ†​ci+1,σ​+h.c.)+i=0∑L−1​Ui​ni↑​ni↓​−i=0∑L−1​σ∑​μi​niσ​,

여기서 ciσ†c^\dagger_{i\sigma}ciσ†​는 사이트 iii에 스핀 σ\sigmaσ의 페르미온을 생성하고, niσ=ciσ†ciσn_{i\sigma} = c^\dagger_{i\sigma} c_{i\sigma}niσ​=ciσ†​ciσ​는 그 개수를 셉니다. 세 항은 사이트 iii와 i+1i+1i+1 사이의 결합에서의 도약 진폭 th,it_{h,i}th,i​, 온사이트 상호작용 UiU_iUi​, 화학 퍼텐셜 μi\mu_iμi​입니다. 이 튜토리얼에서는 에너지를 tht_hth​ 단위로, 시간을 1/th1/t_h1/th​ 단위로 측정합니다.

이 모델의 실시간 동역학은 고전적으로 계산하기 어렵습니다. 정확한 대각화는 L≲14L \lesssim 14L≲14 사이트 근처에서 한계에 이르고, 퀀치(quench) 후에는 텐서 네트워크 솔버의 얽힘 엔트로피가 시간에 따라 선형적으로 증가하므로, 고정된 정확도에 필요한 결합 차원(bond dimension)이 지수적으로 증가합니다.

1차원에서 기본 들뜸은 스핀은 있으나 전하가 없는 스피논(spinon)과, 전하는 있으나 스핀이 없는 홀론(holon)입니다. 두 들뜸은 서로 다른 속도로 전파되므로, 국소적인 교란은 빠른 파면과 느린 파면으로 갈라집니다. 이 효과를 스핀-전하 분리라고 하며, 이 튜토리얼에서 이를 측정합니다 [1].

이 튜토리얼은 해밀토니안, 초기 상태, Trotter 스케줄, 관측량 목록을 받아 기댓값을 반환하는 Dynamics Simulator Qiskit Function을 사용합니다. Jordan-Wigner 매핑, Trotter 분해, 큐비트 레이아웃, 오류 억제를 내부에서 처리하므로, 이 튜토리얼에서는 직접 구성하거나 트랜스파일할 회로가 없습니다.

1단계: 고전적 입력을 양자 문제로 매핑​

해밀토니안 정의​

이 함수는 모델을 세 개의 키가 있는 딕셔너리로 받습니다. 각 키는 사슬 전체에 균일하게 적용되는 단일 float 값, 또는 사이트별로 값을 지정하는 리스트를 받습니다. 리스트는 hopping_amplitude에는 L−1L-1L−1개 항목을 가지는데, 열린 사슬은 사이트보다 결합이 하나 적기 때문입니다. on_site_interaction과 chemical_potential에는 LLL개 항목을 가집니다.

이 튜토리얼은 반발 상호작용 U/th=8U/t_h = 8U/th​=8을 갖는 31개 사이트의 균일한 사슬을 사용합니다. 균일한 화학 퍼텐셜은 입자 수가 고정되어 있을 때 전역 위상만 더하므로, 이 예제에서는 0으로 설정합니다. 화학 퍼텐셜은 사이트마다 달라질 때, 예를 들어 무질서나 단일 불순물을 추가할 때에만 의미가 있습니다.

site_count = 31
hopping_amplitude = 1.0
on_site_interaction = 8.0
chemical_potential = 0.0

model = {
    "hopping_amplitude": [hopping_amplitude] * (site_count - 1),
    "on_site_interaction": [on_site_interaction] * site_count,
    "chemical_potential": [chemical_potential] * site_count,
}

print(
    f"{site_count} sites, {2 * site_count} qubits, U/t_h = {on_site_interaction:.0f}"
)
31 sites, 62 qubits, U/t_h = 8

Trotter 스케줄 설정​

simulation 딕셔너리에는 시간 간격(Δt\Delta tΔt)과 Trotter 단계 수가 들어 있으며, 전체 진화 시간은 이 둘의 곱입니다. 단계가 클수록 회로 깊이를 고정한 채 더 나중 시간까지 도달할 수 있지만 Trotter 오차가 늘어나며, 이 오차는 해밀토니안 항들이 덜 교환하므로 UUU에 따라 커집니다. 발표된 하드웨어 연구는 U/th=8U/t_h = 8U/th​=8에 Δt=0.15\Delta t = 0.15Δt=0.15를 사용했으며 [2], 이 튜토리얼도 같은 값을 사용합니다. 회로 깊이는 단계 수에 비례해 선형적으로 증가하며 LLL에는 전혀 의존하지 않습니다.

time_step = 0.15
step_count = 30

simulation = {"time_step": time_step, "step_count": step_count}

print(
    f"Total evolution time: t = {time_step * step_count:.2f} (units of 1/t_h)"
)
Total evolution time: t = 4.50 (units of 1/t_h)

초기 상태 준비​

각 사이트에는 두 개의 스핀 오비탈이 있으므로 LLL개 사이트의 사슬은 2L2L2L개의 큐비트를 사용합니다. 초기 상태는 사이트당 한 문자로 이루어진 Fock 점유 문자열입니다.

empty (e)⟷(ni,↑,ni,↓)=(0,0),up (u)⟷(ni,↑,ni,↓)=(1,0),down (d)⟷(ni,↑,ni,↓)=(0,1),both (b)⟷(ni,↑,ni,↓)=(1,1).\begin{aligned} \texttt{empty (e)} &\longleftrightarrow \left(n_{i,\uparrow}, n_{i,\downarrow}\right) = (0,0), \\ \texttt{up (u)} &\longleftrightarrow \left(n_{i,\uparrow}, n_{i,\downarrow}\right) = (1,0), \\ \texttt{down (d)} &\longleftrightarrow \left(n_{i,\uparrow}, n_{i,\downarrow}\right) = (0,1), \\ \texttt{both (b)} &\longleftrightarrow \left(n_{i,\uparrow}, n_{i,\downarrow}\right) = (1,1). \end{aligned}empty (e)up (u)down (d)both (b)​⟷(ni,↑​,ni,↓​)=(0,0),⟷(ni,↑​,ni,↓​)=(1,0),⟷(ni,↑​,ni,↓​)=(0,1),⟷(ni,↑​,ni,↓​)=(1,1).​

문자열은 최하위 사이트부터 읽으므로 가장 오른쪽 문자가 사이트 0이며, 왼쪽에서 kkk번째 문자에 해당하는 물리적 사이트 인덱스는 i=L−1−ki = L - 1 - ki=L−1−k입니다. 따라서 문자열 udud는 사이트 0이 d, 사이트 1이 u, 사이트 2가 d, 사이트 3이 u라는 뜻입니다.

다음으로 u와 d가 번갈아 나타나는 반충전 Néel 상태를 준비하되, 중앙 사이트는 빈자리(vacancy)로 바꿉니다. 이 빈자리가 퍼져 나가는 모습을 추적할 교란입니다.

vacancy_site = site_count // 2

# Build in increasing site order, then reverse: the leftmost character of the
# string is the highest site index.
site_occupations = [
    "u" if site % 2 == 0 else "d" for site in range(site_count)
]
site_occupations[vacancy_site] = "e"
initial_state = "".join(reversed(site_occupations))

print(f"Vacancy at site {vacancy_site}")
print(initial_state)
Vacancy at site 15

관측량 구성​

각 관측량은 점유 연산자들의 곱을 가중합으로 나타내는 딕셔너리입니다.

O=∑αcα∏(σ,j)∈Tαnj,σ.O = \sum_{\alpha} c_{\alpha} \prod_{(\sigma, j) \in T_{\alpha}} n_{j,\sigma}.O=α∑​cα​(σ,j)∈Tα​∏​nj,σ​.

operators의 각 항목은 서로 곱해지는 [name, site] 쌍의 리스트로 쓰인 하나의 항 TαT_{\alpha}Tα​이고, coefficients의 대응하는 항목은 그 가중치입니다. 두 이름은 nj,↑n_{j,\uparrow}nj,↑​를 나타내는 "Nup"과 nj,↓n_{j,\downarrow}nj,↓​를 나타내는 "Ndn"입니다. 단일 1점 관측량 n3,↑n_{3,\uparrow}n3,↑​는 다음과 같이 씁니다.

{"operators": [[["Nup", 3]]], "coefficients": [1.0]}

다음 셀은 함수가 받아들이는 가장 작은 완전한 입력 집합을 출력하며, 이어지는 코드를 읽을 때 형태를 참고하는 데 유용합니다.

minimal_inputs = {

세 그룹의 관측량이 필요합니다. 전하 밀도 ni=ni↑+ni↓n_i = n_{i\uparrow} + n_{i\downarrow}ni​=ni↑​+ni↓​와 국소 스핀 Siz=(ni↑−ni↓)/2S^z_i = (n_{i\uparrow} - n_{i\downarrow})/2Siz​=(ni↑​−ni↓​)/2는 모두 같은 연산자에 대한 두 항의 합이며 계수만 다릅니다. 사이트 iii와 빈자리 사이트 사이의 스핀 상관 SizSi∗zS^z_i S^z_{i_*}Siz​Si∗​z​는 계수가 ±1/4\pm 1/4±1/4인 네 개의 2점 항으로 전개됩니다.

점유 연산자는 서로 교환하므로 한 항 안에서 인자의 순서는 중요하지 않지만, observables 리스트의 순서가 반환되는 값의 순서를 결정합니다. 코드는 리스트를 만들면서 각 그룹의 인덱스를 기록합니다. 상관 함수는 곱이 인자를 반복하게 되는 빈자리 사이트를 건너뜁니다.

observables = []
charge_indices = []
spin_indices = []
correlator_indices = []

# Charge density: n_i = n_{i,up} + n_{i,down}
for site in range(site_count):
    charge_indices.append(len(observables))
    observables.append(
        {
            "operators": [[["Nup", site]], [["Ndn", site]]],
            "coefficients": [1.0, 1.0],
        }
    )

# Local spin: S^z_i = (n_{i,up} - n_{i,down}) / 2
for site in range(site_count):
    spin_indices.append(len(observables))
    observables.append(
        {
            "operators": [[["Nup", site]], [["Ndn", site]]],
            "coefficients": [0.5, -0.5],
        }
    )

# Spin correlator: S^z_i S^z_{i_*}, expanded into four two-point terms.
correlator_sites = [
    site for site in range(site_count) if site != vacancy_site
]
for site in correlator_sites:
    correlator_indices.append(len(observables))
    observables.append(
        {
            "operators": [
                [["Nup", site], ["Nup", vacancy_site]],
                [["Nup", site], ["Ndn", vacancy_site]],
                [["Ndn", site], ["Nup", vacancy_site]],
                [["Ndn", site], ["Ndn", vacancy_site]],
            ],
            "coefficients": [0.25, -0.25, -0.25, 0.25],
        }
    )

print(f"{len(observables)} observables")
print("Example correlator:", observables[correlator_indices[0]])

2단계: 양자 하드웨어 실행에 맞게 문제 최적화​

이 튜토리얼에는 트랜스파일 단계가 없습니다. 함수가 다음 단계를 내부적으로 수행하며 [2], 노트북에서는 이를 설정할 수 없습니다.

  • heavy-hex 격자에서 Pauli 가중치가 낮게 유지되도록 선택된 순서로 페르미온 모드를 큐비트에 매핑합니다

  • 모든 도약 항이 2큐비트 회전이 되도록 페르미온 SWAP 네트워크를 사용합니다

  • 약한 큐비트를 피하는 경로를 따라 사슬을 임베딩합니다

  • 컴파일 중에 동적 디커플링과 Pauli 트월링을 적용합니다

상관 함수 재구성​

앞서 기록한 인덱스를 사용해 평평한 배열을 세 그룹으로 다시 나눈 다음, 두 개의 추적자 상관 함수를 구성합니다. 전하 추적자는 t=0t=0t=0 대비 사이트별 밀도의 변화입니다.

Cic(t)=⟨ni↑(t)+ni↓(t)⟩−⟨ni↑(0)+ni↓(0)⟩.C^c_i(t) = \langle n_{i\uparrow}(t) + n_{i\downarrow}(t) \rangle - \langle n_{i\uparrow}(0) + n_{i\downarrow}(0) \rangle.Cic​(t)=⟨ni↑​(t)+ni↓​(t)⟩−⟨ni↑​(0)+ni↓​(0)⟩.

스핀 추적자는 각 사이트와 빈자리 사이트 i∗i_*i∗​ 사이의 연결된 상관 함수입니다.

Cis(t)=4(⟨SizSi∗z⟩−⟨Siz⟩⟨Si∗z⟩).C^s_i(t) = 4 \left( \langle S^z_i S^z_{i_*} \rangle - \langle S^z_i \rangle \langle S^z_{i_*} \rangle \right).Cis​(t)=4(⟨Siz​Si∗​z​⟩−⟨Siz​⟩⟨Si∗​z​⟩).

둘 다 Fock 기저 연산자로 구성되므로 같은 측정 비트열에서 얻어지며, 두 번째 것은 추가 하드웨어 실행 비용이 들지 않습니다.

발표된 연구 [2]의 검출 프로토콜을 따라 히트맵을 숫자로 바꿉니다. 각 시간 조각에서 빈자리를 중심으로 공간 프로파일을 대칭화하여 하드웨어 노이즈의 반대칭 부분을 평균해 없애고, 중심에서 벗어난 가장 큰 진폭으로 정규화한 다음, 임계값을 넘는 가장 바깥쪽 사이트를 기록합니다. 그런 다음 검출 결과를 연속된 시간 단계의 구간으로 나누고, 가장 긴 구간만 피팅하여 초기 과도 구간이 결과에 들어가지 않게 합니다.

def front_distance(profile, center, threshold):
    """Distance from `center` to the outermost site above a relative threshold."""
    values = np.nan_to_num(np.asarray(profile, dtype=float))
    length = values.size

    symmetrized = values.copy()
    for site in range(length):
        mirror = 2 * center - site
        if 0 <= mirror < length:
            symmetrized[site] = 0.5 * (values[site] + values[mirror])

    amplitude = np.abs(symmetrized)
    off_center = np.ones(length, dtype=bool)
    off_center[center] = False

    peak = amplitude[off_center].max()
    if peak <= 0.0:
        return np.nan
    above = np.flatnonzero((amplitude / peak > threshold) & off_center)
    return float(np.abs(above - center).max()) if above.size else np.nan

def longest_run(mask):
    """Indices of the longest run of consecutive True values."""
    best, current = [], []
    for index, keep in enumerate(mask):
        current = current + [index] if keep else []
        if len(current) > len(best):
            best = current
    return np.array(best, dtype=int)

def front_velocity(tracer, center, threshold=0.3, quantile=0.75, min_block=5):
    """Fit front position against time, using only the longest contiguous run."""
    distances = np.array(
        [
            front_distance(tracer[:, k], center, threshold)
            for k in range(tracer.shape[1])
        ]
    )
    edge = max(center, tracer.shape[0] - 1 - center)
    usable = (
        np.isfinite(distances) & (distances >= 2) & (distances <= edge - 2)
    )

    block = longest_run(usable)
    if block.size < min_block:
        return np.nan, distances, np.array([], dtype=int), np.nan

    candidates = [
        stats.theilslopes(distances[block[:k]], times[block[:k]]).slope
        for k in range(min_block, block.size + 1)
    ]
    cutoff = np.quantile(candidates, quantile)
    keep = max(i for i, value in enumerate(candidates) if value >= cutoff)

    fit_block = block[: keep + min_block]
    slope, intercept = np.polyfit(times[fit_block], distances[fit_block], 1)
    return float(slope), distances, fit_block, float(intercept)

피팅된 속도는 검출 임계값과 트리밍 분위수에 의존하며, 이 민감도가 샷 노이즈보다 지배적입니다. 발표된 분석처럼 두 값을 모두 훑어 보고, 전체 범위(envelope)와 함께 중앙값을 보고하세요.

thresholds = [0.15, 0.225, 0.30, 0.375, 0.45]
quantiles = [0.60, 0.675, 0.75, 0.825, 0.90]

def velocity_envelope(tracer, center):
    """Median, minimum, and maximum velocity over the parameter scan."""
    values = [
        front_velocity(tracer, center, threshold=p, quantile=q)[0]
        for p in thresholds
        for q in quantiles
    ]
    values = np.array([v for v in values if np.isfinite(v)])
    if values.size == 0:
        return np.nan, np.nan, np.nan
    return float(np.median(values)), float(values.min()), float(values.max())

전하 파면이 스핀 파면을 앞지릅니다. 1차원 Mott 배경에서 홀(hole)은 전자처럼 이동하지 않습니다. 대신 전하를 나르는 홀론과 스핀 교란을 나르는 스피논으로 분수화되며, U/th=8U/t_h = 8U/th​=8에서는 스피논이 둘 중 더 느립니다.

이 순서는 상호작용에 따라 달라집니다. U=0U = 0U=0에서 모델은 vc=2v_c = 2vc​=2, vs=4v_s = 4vs​=4인 자유 페르미온이므로 스핀이 더 빠릅니다. 반발력은 전하 수송은 거의 그대로 두면서 스핀 수송을 억제하며, U/th=8U/t_h = 8U/th​=8에서 발표된 하드웨어 값은 vc=1.78v_c = 1.78vc​=1.78과 vs=1.46v_s = 1.46vs​=1.46입니다 [2]. 여러 UUU 값으로 다시 실행하고 vs/vcv_s / v_cvs​/vc​를 그리면 교차 지점을 파악할 수 있습니다.

이 수치에 대한 주의 사항입니다. 임계값 기반 검출은 약간 낮게 편향되므로, 전하 속도가 발표된 값보다 몇 퍼센트 낮게 나오는 것은 예상된 결과입니다. 연결된 상관 함수는 노이즈 바닥에 더 가깝기 때문에 스핀 범위가 넓으며, 이 때문에 단일 피팅이 아니라 스캔의 중앙값을 제시합니다.
