Aqarios 제약 양자 최적화기로 최대 독립 집합 찾기

참고

Qiskit Functions는 IBM Quantum® Premium Plan, Flex Plan, On-Prem(IBM Quantum Platform API를 통한) Plan 사용자에게만 제공되는 실험적 기능입니다. 이 기능은 프리뷰 릴리스 상태이며 변경될 수 있습니다.

사용량 추정치: Heron r2 프로세서에서 30초. (참고: 이는 추정치일 뿐이며, 실제 실행 시간은 다를 수 있습니다.)

배경​

이 튜토리얼에서는 Aqarios 제약 양자 최적화기 [1]를 사용하여 그래프의 최대 독립 집합을 찾는 방법을 보여줍니다. 이는 제약이 있는 조합 최적화 문제입니다. QOBLIB [2] 벤치마크 라이브러리의 인스턴스를 이진 선형 프로그램으로 정식화하여 Optimizer Application Function에 전달합니다. 최적화기는 모든 재정식화, 회로 합성, 트랜스파일, 그리고 반복적 웜스타팅을 내부적으로 처리합니다 (자세한 내용은 [3] 참조).

이 튜토리얼은 다음 단계들을 다룹니다.

  1. qiskit-addon-opt-mapper의 OptimizationProblem을 사용하여 문제를 선형 프로그램으로 정의합니다

  2. Aqarios 제약 양자 최적화기를 사용하여 양자 최적화를 실행합니다

  3. 결과를 가져와 시각화해요

최대 독립 집합 문제​

최대 독립 집합(Maximum Independent Set, MIS) 문제는 조합 최적화의 근본적인 과제입니다. 공식적으로, 그래프 G(V,E)G(V, E)G(V,E)가 주어졌을 때, 목표는 VIV_IVI​ 내 어떤 두 정점도 에지로 연결되지 않도록 하는 가장 큰 정점 부분집합 VI⊂VV_I \subset VVI​⊂V를 찾는 것입니다. 이는 ∄(u,v)∈E:v∈VI∧u∈VI\nexists (u, v) \in E : v \in V_I \wedge u \in V_I∄(u,v)∈E:v∈VI​∧u∈VI​로 표현됩니다. 각 정점에는 이진 결정 변수 xi∈{0,1}x_i \in \{0, 1\}xi​∈{0,1}가 할당되며, 각 에지에 대해 제약 조건 xu+xv≤1x_u + x_v \leq 1xu​+xv​≤1이 도입되어 각 에지의 양 끝점 중 최대 하나만 선택되도록 보장합니다. 따라서 이 문제는 다음과 같은 최대화 문제로 표현될 수 있습니다.

max⁡xi∑i∈Vxi(가장 큰 집합 찾기)s.t.xu+xv≤1∀(u,v)∈E.\max_{x_i} \sum_{i \in V} x_i \qquad\text{(가장 큰 집합 찾기)}\\ \text{s.t.} \quad x_u + x_v \leq 1 \quad \forall (u, v) \in E.xi​max​i∈V∑​xi​(가장 큰 집합 찾기)s.t.xu​+xv​≤1∀(u,v)∈E.

MIS는 폭넓은 실제 응용 분야를 갖고 있습니다. 무선 네트워크 계획에서, 독립 집합은 상호 간섭 없이 동시에 방송할 수 있는 송신기 그룹에 해당합니다. 스케줄링에서는, 쌍별 자원 충돌이 있는 상황에서 동시에 실행할 수 있는 최대 작업 집합을 모델링합니다. 계산 생물학에서는, 네트워크에서 서로 상호작용하지 않는 단백질 집합을 나타내요.

직관적인 정식화에도 불구하고, MIS는 NP-난해(NP-hard)이며, 노드가 수백 개에 불과한 그래프에서도 특정 인스턴스는 정확하게 또는 휴리스틱하게 풀기 어려워집니다 [2]. 이 문제는 또한 양자 최적화의 하드웨어 구현에 적합한 희소 제약 구조를 가지고 있어, 근시일 내 양자 장치를 위한 매력적인 벤치마크가 됩니다.

Aqarios 제약 양자 최적화기​

제약이 있는 이진 문제를 양자 최적화에 임베딩하는 표준적인 접근법은 페널티 항을 추가하여 모델을 제약 없는 형태로 변환합니다. 위반된 각 제약 조건 xu+xv≤1x_u + x_v \leq 1xu​+xv​≤1은 최소화 목적함수 −∑ixi-\sum_i x_i−∑i​xi​에 2xuxv2 x_u x_v2xu​xv​를 기여합니다. 이는 제약 양자 최적화기 Qiskit Function에 의해 자동으로 처리됩니다.

이 표준 변환을 넘어서, 최적화기는 제약 그래프 내에서 **클리크(cliques)**를 식별합니다. 클리크는 모든 노드 쌍이 에지를 공유하는 노드 집합 VCV_CVC​입니다. 그 결과, (∣VC∣2)\binom{|V_C|}{2}(2∣VC​∣​)개의 쌍별 제약 조건 xu+xv≤1  ∀(u,v)∈ECx_u + x_v \leq 1 \;\forall (u,v) \in E_Cxu​+xv​≤1∀(u,v)∈EC​를 단일하고 더 강한 제약 조건 ∑i∈VCxi≤1\sum_{i \in V_C} x_i \leq 1∑i∈VC​​xi​≤1로 대체할 수 있습니다. 여유 변수(slack variable) yyy를 도입하면 이는 등식 ∑ixi+y=1\sum_i x_i + y = 1∑i​xi​+y=1이 되며, 이는 QAOA에서 XY-믹서를 사용하여 직접 적용할 수 있는 원-핫(one-hot) 제약 조건의 형태를 취합니다 [3]. 이는 탐색 공간을 줄이고 해당 제약 조건에 대한 페널티 항의 필요성을 없애 해의 품질을 향상시킵니다.

또한, 단 하나의 이웃과만 연결된 변수는 펜던트(pendant) 노드라고 불리며, 양자 실행 전에 알고리즘에 의해 결정론적으로 고정되어 유효 문제 크기를 더욱 줄입니다.

제약 양자 최적화기는 XY-믹서와 호환되는 반복적 웜스타팅(iterative warm-starting) 접근법을 사용합니다 [1]. 이는 반복(iteration)을 거듭하며 양자 상태 분포를 유망한 해 영역 쪽으로 점진적으로 편향시켜 탐색 공간을 좁혀 나갑니다. 이를 통해 **고정 각도 QAOA 파라미터(fixed-angle QAOA parameters)**를 사용할 수 있어 변분 파라미터 훈련이 필요 없게 됩니다. 전체 양자 자원 요구량은 오직 웜스타트 반복 횟수에 의해서만 결정되므로, 양자 비용을 간단하게 제어할 수 있습니다.

1단계: 고전 입력을 양자 문제로 매핑​

이 문제는 최적화 문제에 흔히 쓰이는 형식이자 Aqarios 제약 양자 최적화기의 입력으로 사용되는 LP-파일로 정식화됩니다. LP-파일 외에도, 이 함수는 MPS-파일과 네이티브 Luna Model 표현도 지원합니다. LP-파일은 다음 단계를 거쳐 생성됩니다.

  1. QOBLIB [2]에서 그래프 인스턴스를 가져옵니다

  2. 최적화 문제를 모델링합니다

  3. LP-파일을 생성합니다

문제 인스턴스 그래프 불러오기​

그래프는 DIMACS .gph 형식으로 지정됩니다. 이는 e로 시작하는 줄이 에지를 정의하고, p로 시작하는 줄이 문제 헤더를 정의하며, c로 시작하는 줄은 주석인 줄 기반 형식입니다.

c some-comment
p edge 3 2
e 1 2
e 2 3
...

.gph 파일은 다음 함수를 사용하여 QOBLIB 저장소에서 다운로드할 수 있으며, 이 함수는 파일을 NetworkX 그래프로 파싱하기도 합니다. DIMACS 형식은 1부터 시작하는 노드 라벨링을 사용하며, 여기서는 이를 0부터 시작하는 인덱싱으로 변환합니다.

URL_BASE = "https://raw.githubusercontent.com/ZIB-AOPT/QOBLIB/refs/heads/main/07-independentset/instances/"

def fetch_qoblib_graph(name: str) -> nx.Graph:
    """Fetch and parse the QOBLIB graph file."""
    # Download the .gph file
    file, _ = urllib.request.urlretrieve(URL_BASE + f"{name}.gph")
    with open(file) as f:
        # Read the file contents
        lines = f.readlines()

    # Skip comments
    lines = [line for line in lines if not line.startswith("c")]

    # Read graph definition
    _, _, num_nodes, num_edges = lines[0].split()
    print(f"Loading graph with {num_nodes} nodes and {num_edges} edges.")

    # Parse edge information
    # The .gph format starts node labeling with 1; we need 0 here, so we subtract one.
    split_edges = (line.split() for line in lines[1:])
    edges = [(int(u) - 1, int(v) - 1) for _, u, v in split_edges]

    return nx.Graph(edges)

graph_name = "es60fst02"
graph = fetch_qoblib_graph(graph_name)

이 예제에서는 QOBLIB의 es60fst02 인스턴스를 사용합니다. 이는 노드 186개, 에지 280개로 이루어진 그래프입니다. 제약 양자 최적화기가 사용하는 전처리 단계 덕분에, 이 인스턴스는 156큐비트 Heron 장치에서 풀 수 있습니다. 이 그래프는 matplotlib을 사용하여 시각화할 수 있습니다.

최적화 문제 구성하기​

최대 독립 집합 문제는 OptimizationProblem을 사용하여 직접 정식화할 수 있습니다. 각 그래프 노드는 이진 결정 변수가 되고, 각 에지는 양 끝점 중 최대 하나만 선택되도록 보장하는 제약 조건을 도입합니다.

# Create an OptimizationProblem instance
mis_problem = OptimizationProblem("MIS")

# Add a binary variable for each node
x = mis_problem.binary_var_list(graph.number_of_nodes())

# Maximize the sum of all node variables
mis_problem.maximize(linear={xi.name: 1 for xi in x})

# Add '<= 1' constraints for each edge
for u, v in graph.edges:
    mis_problem.linear_constraint({x[u].name: 1, x[v].name: 1}, "<=", 1)

지름길​

qiskit-addon-opt-mapper 패키지는 최대 독립 집합 문제를 위해 미리 구현된 애플리케이션 클래스를 제공하며, 이를 통해 위의 정식화를 단 한 번의 호출로 단순화할 수 있습니다.

mis = IndependentSet(graph)
mis_problem = mis.to_optimization_problem()

부록: Luna Model을 사용한 문제 서술​

위에서 살펴본 qiskit-addon-opt-mapper 접근법 외에도, 이 Qiskit Function은 Aqarios의 모델링 SDK인 Luna Model [4]로 생성한 모델도 받아들입니다. luna-model PyPI 패키지를 설치한 후, 다음과 같이 임포트합니다.

Setup:

from luna_model import Model, Sense
import numpy as np

그런 다음 모델은 qiskit-addon-opt-mapper와 동일한 방식으로 그래프로부터 구성됩니다. 모델 구성하기:

edges = np.array(graph.edges)

# Create the optimization model with a name
model = Model(name=f"MIS-{graph_name}", sense=Sense.MAX)
# Add binary variables
x = model.add_variables("x", graph.number_of_nodes())
# Set the objective
model.objective = x.sum()

# Use numpy like batch generation of constraints
model.add_constraints(x[edges].sum(axis=1) <= 1)

input_str = model.encode_b64()

# optimizer.run(model=input_str, backend_name="ibm_fez")
