Pauli 상관관계 인코딩을 통한 max-cut 요구사항 감소

사용 시간 예상: Eagle r3 프로세서 기준 35분 (참고: 이는 추정치이며, 실제 실행 시간은 다를 수 있습니다.)

학습 결과​

  • 다체(multi‑body) Pauli 문자열이 어떻게 고전 최적화 문제의 다항식 압축을 가능하게 하는지를 포함하여 Pauli 상관관계 인코딩(PCE)의 이론적 원리를 이해합니다.

  • 근미래 양자 하드웨어에서 대규모 최적화 작업을 인코딩하고 풀기 위해 실제로 PCE를 구현합니다.

사전 요구사항​

  • 변분 양자 알고리즘

  • QAOA와 max-cut

배경​

이 튜토리얼에서는 Pauli 상관관계 인코딩 (PCE) [1]을 소개합니다. PCE는 양자 계산에서 더 높은 효율로 최적화 문제를 Qubit에 인코딩하도록 설계된 접근 방식입니다. PCE는 최적화 문제의 고전 변수를 다체(multi-body) Pauli 행렬 상관관계에 매핑하여 문제의 공간 요구사항을 다항식적으로 압축합니다. PCE를 사용하면 인코딩에 필요한 qubit 수가 줄어들어, 제한된 qubit 자원을 가진 근미래 양자 장치에 특히 유리합니다. 또한, PCE가 본질적으로 바렌 플래토(barren plateau) 문제를 완화하며, 이 현상에 대해 초다항식적 내성을 갖는다는 것이 분석적으로 증명되었습니다. 이러한 내장 기능은 양자 최적화 솔버에서 전례 없는 성능을 가능하게 합니다.

개요​

PCE 접근 방식은 아래 [1]의 그림 1에 나타난 것처럼 세 가지 주요 단계로 구성됩니다:

  1. 최적화 문제를 Pauli 상관관계 공간으로 인코딩합니다.
  2. 양자-고전 최적화 솔버를 사용하여 문제를 풉니다.
  3. 해를 원래 최적화 공간으로 디코딩합니다. PCE 접근 방식은 Pauli 상관관계 행렬을 처리할 수 있는 모든 양자 최적화 솔버에 적용 가능합니다. [1]의 그림 1에서 max-cut 문제를 PCE 접근 방식을 설명하는 예시로 사용합니다. m=9m=9m=9 노드의 max-cut 문제는 Pauli 상관관계 공간으로 인코딩되어, 최적화 문제를 상관관계 행렬, 구체적으로는 n=3n=3n=3 qubit (Q1,Q2,Q3)(Q_1, Q_2, Q_3)(Q1​,Q2​,Q3​)에 걸친 2체(two-body) Pauli 행렬 상관관계로 나타냅니다. 노드의 색상은 각 인코딩된 노드에 사용된 Pauli 문자열을 나타냅니다. 예를 들어, 이진 변수 x1x_1x1​에 해당하는 노드 1은 Z1⊗Z2⊗I3Z_1 \otimes Z_2 \otimes I_3Z1​⊗Z2​⊗I3​의 기댓값으로 인코딩되며, x8x_8x8​은 I1⊗Y2⊗Y3I_1 \otimes Y_2 \otimes Y_3I1​⊗Y2​⊗Y3​으로 인코딩됩니다. 이는 문제의 mmm개 변수를 n=O(m1/2) n = O(m^{1/2})n=O(m1/2) Qubit으로 압축하는 것에 해당합니다. 더 일반적으로, k>1k>1k>1인 kkk체 상관관계는 kkk차 다항식 압축을 가능하게 합니다. 선택된 Pauli 집합은 상호 가환(mutually-commuting) Pauli 문자열의 세 가지 부분 집합으로 구성되어 있어, 단 세 가지 측정 설정으로 모든 mmm개의 상관관계를 실험적으로 추정할 수 있습니다.

원래 max-cut 목적 함수를 모방하는 Pauli 기댓값의 손실 함수 L\mathcal{L}L이 구성됩니다. 그런 다음, VQE(Variational Quantum Eigensolver)와 같은 양자-고전 최적화 솔버를 사용하여 손실 함수를 최적화합니다.

최적화가 완료되면, 해는 원래 최적화 공간으로 디코딩되어 최적의 max-cut 해를 산출합니다.

def make_cut_evaluator(problem):
    """Return a function that maps a 0/1 node assignment to its cut value.

    The objective of the max-cut ``OptimizationProblem`` is the cut value
    itself, and ``problem.objective.evaluate`` computes it for one
    assignment. The swap search in Step 4 evaluates one candidate
    assignment per edge, so pull the objective's coefficients out once
    and evaluate them as a sparse matrix product instead.
    """
    quadratic = problem.objective.quadratic.coefficients.tocsr()
    linear = problem.objective.linear.to_array()
    constant = problem.objective.constant

    def evaluate_cut(bits):
        x = np.asarray(bits, dtype=float)
        return int(round(constant + linear @ x + x @ (quadratic @ x)))

    return evaluate_cut

max-cut 문제​

max-cut 문제는 그래프 G=(V,E)G = (V, E)G=(V,E)에서 정의되는 조합 최적화 문제로, VVV는 꼭짓점의 집합이고 EEE는 간선의 집합입니다. 목표는 두 집합 SSS와 V∖SV \setminus SV∖S 사이의 간선 수가 최대가 되도록 꼭짓점을 두 집합으로 분할하는 것입니다. max-cut 문제에 대한 자세한 설명은 양자 근사 최적화 알고리즘 튜토리얼을 참조하세요. 또한, max-cut 문제는 QAOA를 위한 고급 기법 튜토리얼에서도 예시로 사용됩니다. 해당 튜토리얼들에서는 QAOA 알고리즘을 사용하여 max-cut 문제를 풉니다.

100개의 노드를 가진 그래프를 9개의 Qubit에 걸친 2체 Pauli 행렬 상관관계로 인코딩합니다(아래 설명 참조). 그래프는 상관관계 행렬로 표현되며, 각 노드는 Pauli 문자열로 인코딩됩니다. Pauli 문자열의 기댓값의 부호가 해당 노드의 분할을 나타냅니다. 예를 들어, 노드 0은 Pauli 문자열 ∏0=I8⊗...I2⊗X1⊗X0\prod_0 = I_{8} \otimes ... I_2 \otimes X_1 \otimes X_0∏0​=I8​⊗...I2​⊗X1​⊗X0​으로 인코딩됩니다. 이 Pauli 문자열의 기댓값의 부호가 노드 0의 분할을 나타냅니다. ∏\prod∏에 대한 Pauli 상관관계 인코딩 (PCE)을 다음과 같이 정의합니다:

xi≔sgn(⟨∏i⟩),x_i \coloneqq \textit{sgn}(\langle\prod_i \rangle),xi​:=sgn(⟨∏i​⟩),

여기서 xix_ixi​는 노드 iii의 분할이고, ⟨∏i⟩≔⟨ψ∣∏i∣ψ⟩\langle \prod_i \rangle \coloneqq \langle \psi |\prod_i| \psi \rangle ⟨∏i​⟩:=⟨ψ∣∏i​∣ψ⟩는 양자 상태 ∣ψ⟩|\psi \rangle∣ψ⟩에 대한 노드 iii를 인코딩하는 Pauli 문자열의 기댓값입니다. 이제 PCE를 사용하여 그래프를 해밀토니안으로 인코딩해 보겠습니다. 노드를 S1S_1S1​, S2S_2S2​, S3S_3S3​ 세 집합으로 나눕니다. 그런 다음, 각 집합의 노드를 각각 XXX, YYY, ZZZ Pauli 문자열을 사용하여 인코딩합니다. 모든 노드를 인코딩하는 데 필요한 노드 수와 qubit 수 사이의 관계를 구해야 합니다. 인코딩에 가능한 모든 순열을 사용하면 다음과 같습니다:

m=3(nk).m=3\binom{n}{k}.m=3(kn​).

이 예제에서는 k=2k=2k=2를 사용하므로,

m=32n(n−1).m = \frac{3}{2} n(n-1).m=23​n(n−1).

따라서, 특정 노드 수 mmm을 표현하는 데 필요한 qubit 수 nnn은 다음과 같습니다:

def build_pauli_correlation_encoding(pauli, node_list, n, k=2):
    pauli_correlation_encoding = []
    for idx, c in enumerate(combinations(range(n), k)):
        if idx >= len(node_list):
            break
        paulis = ["I"] * n
        paulis[c[0]], paulis[c[1]] = pauli, pauli
        pauli_correlation_encoding.append(("".join(paulis)[::-1], 1))

    hamiltonian = []
    for pauli, weight in pauli_correlation_encoding:
        hamiltonian.append(SparsePauliOp.from_list([(pauli, weight)]))

    return hamiltonian

손실 함수​

손실 함수 L\mathcal{L}L으로, [1]에 설명된 max-cut 목적 함수의 완화된 형태를 사용합니다. 이는 V(x)≔∑(i,j)∈EWi,j(1−xixj)\mathcal{V}(\mathbf{x}) \coloneqq \sum_{(i, j) \in E} W_{i, j}(1-x_i x_j)V(x):=∑(i,j)∈E​Wi,j​(1−xi​xj​)로 정의됩니다. 여기서 Wi,jW_{i, j}Wi,j​는 간선 (i,j)(i, j)(i,j)의 가중치를 나타내고, xix_ixi​는 노드 iii의 분할을 나타냅니다. 손실 함수 L\mathcal{L}L은 다음과 같이 정의됩니다:

def loss_func_estimator(x, ansatz, hamiltonian, estimator, graph):
    """
    Calculates the specified loss function for the given ansatz, Hamiltonian,
    and graph.

    The expectation values of each Pauli string in the Hamiltonian are first
    obtained by running the ansatz on the quantum backend. These
    expectation values are then passed through the nonlinear function
    tanh(alpha * prod_i). The loss function is
    subsequently computed from these transformed values.
    """
    job = estimator.run(
        [
            (ansatz, hamiltonian[0], x),
            (ansatz, hamiltonian[1], x),
            (ansatz, hamiltonian[2], x),
        ]
    )
    result = job.result()

    # calculate the loss function
    node_exp_map = {}
    idx = 0
    for r in result:
        for ev in r.data.evs:
            node_exp_map[idx] = ev
            idx += 1

    loss = 0
    alpha = num_qubits
    for edge0, edge1 in graph.edge_list():
        loss += np.tanh(alpha * node_exp_map[edge0]) * np.tanh(
            alpha * node_exp_map[edge1]
        )

    regulation_term = 0
    for i in range(len(graph.nodes())):
        regulation_term += np.tanh(alpha * node_exp_map[i]) ** 2
    regulation_term = regulation_term / len(graph.nodes())
    regulation_term = regulation_term**2
    beta = 1 / 2
    v = len(graph.edges()) / 2 + (len(graph.nodes()) - 1) / 4
    regulation_term = beta * v * regulation_term

    loss = loss + regulation_term

    global experiment_result
    print(f"Iter {len(experiment_result)}: {loss}")
    experiment_result.append({"loss": loss, "exp_map": node_exp_map})
    return loss

# Swap the partitions and calculate the cut size

def swap_partitions(graph, cur_bits, evaluate_cut):
    best_cut = 0
    best_bits = []
    for edge0, edge1 in graph.edge_list():
        swapped_bits = cur_bits.copy()
        swapped_bits[edge0], swapped_bits[edge1] = (
            swapped_bits[edge1],
            swapped_bits[edge0],
        )
        cut_size = evaluate_cut(swapped_bits)
        if best_cut < cut_size:
            best_cut = cut_size
            best_bits = swapped_bits
    return best_cut, best_bits
